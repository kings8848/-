# H03 · CS 답변·후기 답글 하네스

## 1. 목적과 위임 단계
- 목적: 고객 문의와 후기에 **정확하고 따뜻한 답변 초안**을 빠르게 만든다
- 위임 단계: **3** → 배송 문의처럼 충분히 검증된 유형은 **4**로 승격 (분기 검토)
- 대표만 하는 일: 품질·클레임 판단, 환불·교환 결정, VIP 응대

## 2. 역할

| 역할 | 맡은 일 | 명세 6칸 요약 |
|---|---|---|
| **C1 분류기** (규칙 우선) | 키워드 규칙으로 유형 분류, 모호하면 AI 판단 | 유형: 배송·파손·품질·선물·대량·교환반품·기타 |
| **C2 정보 결합** (규칙) | 주문·송장·배송 상태·병입로트·검사 기록을 붙인다 | AI 아님. 개인정보는 필요한 항목만 |
| **C3 답변 작성자** | 템플릿 + 결합 정보로 답변 초안 | 맥락: 킹스양조장 대표가 직접 쓰는 말투 / 조건: 확인되지 않은 약속 금지, 보상 언급 금지(대표 결정 사항) / 형식: 인사-답-다음 행동-마무리, 5문장 이내 |
| **C4 검사자** | 사실·약속·말투·개인정보 점검 | **C3과 다른 AI 또는 규칙 검사** |

## 3. 순서
`C1 분류 → C2 정보 결합 → C3 초안 → C4 검사 → 대표 승인 → 발송 → 기록`
품질·파손 유형은 C3 초안과 함께 **역추적 보고서**(병입로트 → 원료·공정)를 대표에게 바로 올린다.

## 4. 넘김
`cs_tickets` 한 건에 `초안`, `검사 결과`, `승인 여부`, `발송 시각`을 기록한다.

## 5. 검수
| 기준 | 판정 |
|---|---|
| 배송일·송장·수량 등 사실이 결합 정보와 다르다 | 치명 |
| 대표 승인 없는 환불·보상·교환 약속 | 치명 |
| 다른 고객의 정보가 섞였다 | 치명 |
| 품질 문제를 단정하거나 부정한다 | 치명 |
| 5문장 초과, 딱딱한 말투 | 주의 |

### 후기 답글 기준
- 평점 4~5: 감사 + 구체적 언급(선물·페어링 등) + 다음 시즌 소식 한 줄
- 평점 3 이하: 사과 + 확인 약속 + CS 연결 (답글로 논쟁하지 않는다)
