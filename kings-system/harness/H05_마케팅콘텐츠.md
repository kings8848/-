# H05 · 마케팅 콘텐츠 하네스

## 1. 목적과 위임 단계
- 목적: 매주 SNS 2건, 월 2건 블로그(루프 질문 답), 시즌 안내 문구를 **브랜드 각본에 맞게** 만든다
- 위임 단계: **3**
- 대표만 하는 일: **실사진·실영상 촬영**, 최종 승인, 대표 이름으로 쓰는 글의 마지막 문장

## 2. 역할

| 역할 | 맡은 일 | 명세 6칸 요약 |
|---|---|---|
| **E1 기획자** | 이번 주 소재 선정 (계절 원료, 공정, 시즌, 루프 질문, 후기) + **월 1회 상위 콘텐츠 해부** | 자료: 생산 일정, 캠페인 일정, 루프 질문 지도, 지난 콘텐츠 반응, **상위 콘텐츠 해부 결과** / 형식: 소재 3개 + 이유 (어떤 고객 의심을 지우는가) |
| **E2 작성자** | 채널별 글 초안 | 맥락: 고객(선물하는 40~60대, 전통주 애호가) / 자료: 브랜드 각본, 문장 은행, H02 사양 / 조건: 사진은 대표가 찍은 실사진 기준으로 설명 / 형식: 채널별 길이 |
| **E3 준수 검사자** | 주류 광고 기준, 금지어, 사실 대조 | **E2와 다른 AI** / 기준: docs/09 A7 |
| **E4 톤 편집자** | 브랜드 각본 톤 통일, 중복 제거 | 기준: 고객이 주인공, 대표는 가이드 |

## 3. 순서
`E1 기획 → 대표 소재 선택·촬영 → E2 초안 → E3 준수 검사 → E4 톤 편집 → 대표 승인 → 게시 → 반응 기록`

## 4. 넘김
`01_소재.md` → (대표 사진 폴더) → `02_초안.md` → `03_준수검사.md` → `04_편집본.md` → `contents` 테이블 기록
