# H04 · 월간 경영 보고 하네스

## 1. 목적과 위임 단계
- 목적: 매월 1일, 규칙 프로그램이 집계한 숫자를 바탕으로 **1쪽 경영 보고서와 해설**을 만들고, 이상 신호를 짚는다
- 위임 단계: **3**
- 대표만 하는 일: 다음 달 결정 3가지 (생산·판매·투자)

## 2. 역할

| 역할 | 맡은 일 | 명세 6칸 요약 |
|---|---|---|
| **D1 집계기** (규칙) | 매출(채널별)·원가·마진·재고·현금·정산·캠페인·출고·CS·AI 비용·위임 비율 집계 | AI 아님. 숫자의 유일한 출처 |
| **D2 해설자** | 숫자의 변화를 3~5문장으로 설명 | 조건: 숫자는 D1 값만 인용, 원인 추정은 "추정"으로 표시 / 형식: 블록별 해설 |
| **D3 이상 탐지자** | 전월·전년 대비 큰 변화, 목표 미달, 위험 신호 표시 | 기준: 매출 ±20%, 재고 안전재고 미달, 미정산, 반품률 상승, AI 비용 예산 초과 |
| **D4 검사자** | 인용 숫자 대조, 과장·단정 점검 | **D2·D3과 분리** |

## 3. 순서
`D1 집계 → (D2 해설 ∥ D3 이상 탐지) → D4 검사 → 대표 확인 → 결정 3가지 기록`

## 4. 넘김
`01_집계.json` → `02_해설.md` / `03_이상신호.md` → `04_검사.md` → `05_월간보고_YYYY-MM.pdf`

## 5. 보고서 1쪽 구성
| 블록 | 내용 |
|---|---|
| 엔진 | 매출·채널별·신규/재구매·캠페인 ROI·엔진 균형 |
| 날개 | SKU별 판매·마진, 한정판 소진율 |
| 동체 | 비용 구조, **AI 비용** |
| 연료 | 현금·정산 예정·미수금 |
| 출고·서비스 | 당일 출고율, 지연·파손·반품, CS 응답 시간, 후기 평점 |
| 입구 | AI 간택 진단 결과 (H06) |
| 위임 | 3·4단계 업무 비율, 하네스 통과율·되돌림률 |
| 다음 달 | 세무·지원사업·시즌 일정, **대표 결정 3가지** |

## 6. 검수
| 기준 | 판정 |
|---|---|

| 추정을 사실처럼 단정했다 | 주의 |
| 이상 신호가 있는데 해설에서 빠졌다 | 주의 |
