# 비전 · 방향 · 꼭 해야 할 일 · 성과 (한 장 요약)

> 표시: [대표] 대표가 정한 것 · [확인] 출처로 확인 · [추정] Claude의 제안
> 목표 수치는 넣지 않았다. 현재 값을 먼저 측정한 뒤 대표가 정한다.

## 1. 비전 [대표]
대표 한 사람이 소유하고 지휘하되, 판매·고객관리·운영은 시스템과 실행 파트너가 지속하는 회사.
AI가 막혀도 멈추지 않는 1인 6차산업 양조장.

## 2. 방향 3가지 [추정 — 대표의 목표를 정리한 것]
| 방향 | 지금 → 3년 뒤 |
|---|---|
| 운영 | 기억과 손작업 → 기록 → 연결 → 자동 → AI 없이도 도는 운영 |
| 매출 | 일반 판매 → 전통주만 들어갈 수 있는 자리 + 소량 맞춤 + AI 추천 대비 (법령 확인 후) |
| 대표 | 모든 일을 직접 실행 → 방향·기준·예외만 맡고 맛과 제품은 끝까지 직접 |

## 3. 꼭 해야 할 일 (순서대로)
| # | 할 일 | 왜 먼저인가 | 완료 기준 |
|---|---|---|---|
| 1 | 대표 정보 6가지 확정 (면허 종류, 원료 비율, 제품 사양, 옹기 수, 기록 방식, 세무사) | 모든 설계·전략의 전제 | 6가지 답변 |
| 2 | 세무사·기관 확인 (주세·장부·통신판매·청탁금지법·고향사랑기부제) | 확인 없이 실행하면 법적 위험 | 질의별 회신 기록 |
| 3 | 매일 기록 + 백업 (배치·출고·증빙) | 자동화는 기록 위에서만 선다 | 30일 연속 기록, 백업 복구 성공 |
| 4 | 1단계 프로그램 (주문·재고·출고·원가) | 대표 시간을 가장 많이 돌려준다 | 한 달 출고를 시스템으로 처리 |
| 5 | 스마트스토어 상품 정보·후기 정비 | 노출 전 기반이 먼저 | 고객 의심 10개에 답한 상세페이지 |
| 6 | 시즌 판매 실험 1~2개 (기업 선물, 확인되면 고향사랑기부제) | 전략이 실제로 팔리는지 데이터로 확인 | 실험 결과 기록 |
| 7 | 권한표·위임장 확정 | 자율 운영의 전제 | 대표 결재 v1 |
| 8 | 차단·부재 리허설 | 비전을 시험으로 증명 | 4장 시험 통과 |

## 하지 않을 일
- 확인 전 법적 표현 사용 (청탁금지법 기준, 분양·선판매 등)
- 노출 전 점검표를 통과하지 않은 상품의 광고
- 신규 구축 프로젝트 동시 3개 이상 [대표]
