## 5. 유튜브의 한계를 넘는 방법 — "주 1회 실험"

유튜브는 **남의 일반론**을 알려준다. 매출은 **내 데이터로 확인한 것**에서 나온다.

```
가설 1개 → AI로 제작 → 실행 → 결과 측정 → 기록 (진화 노트)
예) "제품명보다 '한우 페어링'을 제목에 넣으면 클릭이 늘 것이다"
    → H05로 두 가지 제목 작성 → 1주씩 게시 → 클릭·주문 비교 → 이긴 쪽을 표준으로
```

| 규칙 | 내용 |
|---|---|
| 한 번에 하나 | 주 1회, 실험은 1개만 |
| 숫자로 판정 | 클릭·문의·주문·후기 중 하나를 미리 정한다 |
| 기록 | `contents`·`campaigns` 테이블과 진화 노트에 남긴다 |
| 유튜브 활용법 | 아이디어 출처로만 쓰고, 채택 여부는 실험으로 정한다 |
