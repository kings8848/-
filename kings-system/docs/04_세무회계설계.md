# 04. 세무·회계 설계

> ⚠️ 이 문서의 기한·세율·서식은 **설계용 초안**이다. 법령과 기준은 바뀌므로 표시된 항목은
> 반드시 담당 세무사·관할 세무서에 확인 후 `tax_calendar`, `liquor_tax_rates` 테이블에 확정 입력한다.
> 시스템의 역할은 **신고를 대신하는 것이 아니라, 신고 자료를 정확하게 자동으로 만들어 세무사에게 넘기는 것**이다.

## 1. 세무 캘린더 (12월 결산 법인 기준 초안)

| 시기 | 항목 | 시스템 산출물 | 확인 |
|---|---|---|---|
| 매월 10일 | 원천세 신고·납부 (대표 급여 지급 시) | 급여 지급 내역 | 세무사 |
| 매월 10일 | 4대보험 납부 | 납부 확인 체크 | — |
| 매월 (반출 다음 달) | **주세 신고·납부** | 월별 반출 집계표 (주종·도수·용량·수량·출고가) | **기한·세율·경감 적용 확인 필요** |
| 1·4·7·10월 25일 | 부가세 신고 (예정·확정) | 매출·매입 집계표, 세금계산서 목록 | **예정고지 대상 여부 확인 필요** |
| 3월 말 | 법인세 신고 | 연간 결산 패키지 | 세무사 |
| 4월 말 | 법인지방소득세 | — | 세무사 |
| 8월 말 | 법인세 중간예납 | 상반기 실적 | 세무사 |
| 연 1회 이상 | 주류 관련 정기 보고·면허 사항 | 제조·반출 실적 | **관할 세무서 확인 필요** |

→ 시스템은 매일 아침 **D-7, D-3, D-day 알림**을 띄운다.

## 2. 주세 자료 흐름 (T-03)

```
출고 입력(S-03) → shipments (반출 대상 여부) → v_monthly_release (월별 집계)
   → liquor_tax_rates (주종별 방식·세율, 경감 조건) → 주세 신고 보조표 → 세무사 / 홈택스
```

| 집계 항목 | 내용 |
|---|---|
| 기간 | 반출 월 |
| 구분 | 주종, SKU, 용량, 알코올도 |
| 수량 | 병 수, 총 용량(L), 순알코올량 |
| 금액 | 출고가 기준 금액 (과세표준 산정 기준은 **세무사 확인**) |
| 제외 | 반품·시음·견본 등 처리 기준 **확인 필요** |
| 경감 | 전통주 주세 경감 적용 여부·한도 **확인 필요** → 연간 누적 출고량 자동 표시 |

## 3. 주류 제조 관련 장부 (T-08)

생산·출고 데이터에서 자동으로 출력한다. 서식은 관할 기관 요구에 맞춰 확정한다 **(확인 필요)**.

| 장부 | 데이터 출처 |
|---|---|
| 원료 수불 (입고·사용·잔량) | material_lots + inventory_moves |
| 제조 기록 (담금·발효·증류·병입) | batches, distillations, bottlings |
| 반출 기록 (일자·수량·도수·반출처) | shipments + order_items |
| 재고 (원액·완제품) | v_stock |

## 4. 증빙 자동 수집·분류 (T-01)

### 흐름
1. 주 1회 홈택스(세금계산서·현금영수증)와 카드사에서 **엑셀 다운로드** → `50_세무회계/수집함/`에 저장
2. 프로그램이 자동으로 읽어 `expenses`에 등록 (중복 자동 제거)
3. **거래처·키워드 규칙**으로 계정과목 자동 분류
4. 분류 안 된 건만 대표가 확인 (목표: 주 5분)

### 자동 분류 규칙 예시 (규칙 테이블로 관리)
| 거래처·키워드 | 계정과목 | 원가 구분 |
|---|---|---|
| 병·마개·라벨 업체 | 원재료비(부자재) | 직접 |
| 쌀·누룩·원료 농가 | 원재료비 | 직접 |
| 한전 | 전력비 | 공통 (증류분은 배부) |
| 가스 | 연료비 | 직접(증류) |
| 택배사 | 운반비 | 판매비 |
| 스마트스토어 수수료 | 지급수수료 | 판매비 |
| 인쇄·디자인 | 광고선전비 | 판매비 |

### 지원사업 회계 (T-11)
- 비용에 `grant_id`를 붙이면 사업별 **정부지원금 / 자부담** 집행 내역이 자동 집계된다.
- 증빙 파일 경로를 같이 저장 → 정산 시 사업별 증빙 묶음 폴더 자동 생성.

## 5. 월 결산 보고서 (T-10) — 1페이지

| 블록 | 내용 |
|---|---|
| 매출 | 채널별 매출, 전월·전년 대비 |
| 원가·마진 | SKU별 병당 원가, 마진율 |
| 생산 | 이번 달 담금·증류·병입 배치, 수율 |
| 재고 | 완제품 재고(병), 원액 재고(L·순알코올), 부족 부자재 |
| 현금 | 입금 예정(플랫폼 정산), 지급 예정, 미수금 |
| 세무 | 다음 달 신고 일정, 예상 주세·부가세 |
| 지원사업 | 진행 사업 집행률, 마감 일정 |

## 6. 세무사 협업 방식

| 주기 | 전달 패키지 (자동 생성 폴더) |
|---|---|
| 매월 | 주세 집계표, 매출·매입 목록, 급여 내역 |
| 분기 | 부가세 자료 (세금계산서·카드·현금영수증 집계) |
| 연 1회 | 결산 패키지 (연간 장부, 재고 평가, 지원금 내역, 고정자산 목록) |

→ 세무사가 쓰는 회계 프로그램 양식을 받아 **내보내기 형식을 맞추는 것**이 1단계 과제.
