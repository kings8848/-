# 07. 구축 로드맵

> 원칙: **작게 만들어 바로 쓰고, 쓰면서 늘린다.** 각 단계가 끝나면 그 부분은 실제 업무에 사용한다.

## 단계별 일정

| 단계 | 기간 | 목표 | 완료 기준 |
|---|---|---|---|
| **0. 기초** | 1~2주 | 설계 확정, 기준 정보 입력 | 품목·SKU·거래처·설비·필지 마스터 입력 완료 |
| **1. 생산·재고·원가** | 3~6주 | 담금~병입 기록, 수불 원장, 병당 원가 | 실제 배치 1개를 시스템으로 끝까지 기록 |
| **2. 판매·출고·주세** | 7~9주 | 주문 통합, 출고, 주세 집계 | 한 달 출고를 시스템으로 처리, 주세 집계표 세무사 확인 |
| **3. 세무·사무** | 10~12주 | 증빙 분류, 월 결산, 일정·알림, 지원사업 | 월 결산 보고서 1회 자동 생성 |
| **4. AI층·지식층** | 13~15주 | AI 연결부, 로컬 AI, 문서 검색 | provider 전환 테스트 통과 |
| **5. 차단 리허설** | 16주 | 인터넷 끊고 1주 운영 | 업무 중단 0건, 보완 목록 처리 |
| **6. 확장** | 이후 | 1차 농업 상세, 센서, 체험, 수출, QR 스토리 | 단계별 |

## 단계별 체크리스트

### 0단계: 기초
- [ ] 설계 문서 검토, 실제와 다른 부분 표시
- [ ] 봉신설주 등 제품별 실제 공정 순서 확정
- [ ] 품목 목록 (원료·부자재·완제품) 작성
- [ ] SKU 목록과 가격표 (소매·도매·수출)
- [ ] 설비·용기 목록 (용량)
- [ ] 거래처·농가 목록
- [ ] 세무사에게 확인: 주세 기한·세율·경감, 주류 장부 서식, 회계 프로그램 양식
- [ ] PC 확정, 외장하드 2개 준비

### 1단계: 생산·재고·원가
- [ ] DB 생성, 마스터 입력
- [ ] 현장 입력 화면 (휴대폰): 입고, 담금, 발효 측정, 증류, 숙성, 병입
- [ ] 번호 자동 발행, 수불 원장 자동 기록
- [ ] 병당 원가 계산
- [ ] 자동 백업
- [ ] 실제 배치 1개로 검증

### 2단계: 판매·출고·주세
- [ ] 채널별 주문 엑셀 가져오기
- [ ] 성인 인증 확인, 선입선출 로트 배정
- [ ] 택배 업로드 파일
- [ ] 주세 반출 집계표 → 세무사 검토
- [ ] 주류 장부 출력

### 3단계: 세무·사무
- [ ] 증빙 가져오기 + 분류 규칙 30개
- [ ] 월 결산 보고서
- [ ] 통합 일정·알림 (세무·인허가·지원사업·계약)
- [ ] 지원사업 증빙 묶음

### 4단계: AI층·지식층
- [ ] 폴더 체계로 기존 파일 이전
- [ ] 문장 은행 (브랜드·CS·지원사업)
- [ ] AI 연결부 + cloud/local/off 전환
- [ ] 로컬 AI 설치·모델 라이선스 확인

### 5단계: 차단 리허설
- [ ] 인터넷 차단 상태로 1주 운영
- [ ] 멈춘 업무 기록 → 보완
- [ ] 복구 테스트 (백업에서 새 PC로 복원)
- [ ] 대표 부재 매뉴얼 작성

## 대표님이 지금 준비할 자료

| 자료 | 용도 | 형태 |
|---|---|---|
| 현재 쓰는 엑셀·장부 (있는 그대로) | 기존 구조 살리기 | 파일 또는 사진 |
| 제품별 공정 순서 (메모 수준) | 생산 모듈 설계 | 메모 |
| 품목·부자재 목록 | 마스터 데이터 | 메모 |
| 판매 채널과 최근 주문 엑셀 1개씩 | 가져오기 양식 | 파일 |
| 세무사 연락 결과 (위 확인 항목) | 세무 모듈 확정 | 메모 |
| 사용 PC 종류 (윈도우/맥) | 설치 방식 | — |
