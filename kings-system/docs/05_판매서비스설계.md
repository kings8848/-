# 05. 판매·서비스 설계 (3차 산업)

## 1. 판매 채널

| 채널 | 주문 수집 방식 | 자동화 | 주의 |
|---|---|---|---|
| 스마트스토어 등 오픈마켓 | 주문 엑셀 다운로드 → 자동 가져오기 | S→A | 전통주 통신판매 요건, **성인 인증** |
| 자사몰 | 주문 엑셀 / 연동 | S→A | 성인 인증 |
| 전화·문자·방문 | 간편 입력 화면 | S | 성인 확인 기록 |
| B2B (음식점·바·선물업체) | 발주서 → 입력 | S | 거래명세서·세금계산서, 미수금 |
| 선물용 한정판 사전예약 | 예약 폼 → 가져오기 | S | 한정 수량 초과 차단, **넘버링** |
| 체험 현장 판매 | 현장 입력 | S | 체험 매출과 구분 |
| 수출 | 건별 입력 | S | 수출 서류, 국가별 라벨 |

**원칙:** 채널이 달라도 모든 주문은 `orders` 한 곳으로 모인다.

## 2. 주문 → 출고 → 정산 흐름

```
[주문 수집]  → [성인 인증 확인] → [재고·출고가능 확인] → [출고 확정] → [송장] → [배송 완료] → [정산 대사]
 S-01          S-02 (미인증 차단)    검사 합격 로트만       재고 −          택배 엑셀    상태 갱신       S-04
                                    (선입선출 로트 추천)    주세 반출 기록
                                                          고객 이력 +
```

| 단계 | 대표가 하는 일 | 시스템이 하는 일 |
|---|---|---|
| 주문 수집 | 채널별 엑셀을 수집함 폴더에 저장 | 읽기, 중복 제거, 주문 통합 |
| 출고 준비 | 오늘 출고 목록 확인 | 품목별 피킹 목록, 병입로트 자동 배정(선입선출) |
| 출고 확정 | 버튼 1번 | 재고 차감, 반출 기록, 택배 업로드용 엑셀 생성 |
| 송장 | 택배사 시스템에 업로드 | 송장번호 가져와 채널 업로드용 파일 생성 |
| 정산 | 주 1회 정산 엑셀 저장 | 주문 대비 입금·수수료 대사, 미입금 목록 |

## 3. 고객 관리 (C-03)

| 항목 | 기준 (초안) |
|---|---|
| 고객 등급 | 신규(1회) / 재구매(2회 이상) / 단골(연 3회 또는 연 30만 원 이상) / VIP(선물 대량·B2B) |
| 자동 목록 | 명절 4주 전 재구매 안내 대상, 6개월 미구매 고객, 한정판 우선 안내 대상 |
| 동의 관리 | 마케팅 수신 동의자만 안내 발송 |
| 개인정보 | 내 PC DB에만 저장, 외부 AI 입력 금지, 보관 기간 정책 수립 **(개인정보 보호 기준 확인 필요)** |

## 4. 시즌 운영 (S-07)

| 시즌 | D-60 | D-30 | D-14 | D-7 | 사후 |
|---|---|---|---|---|---|
| 설 | 한정판 기획, 부자재 발주 | 병입, 상세페이지 | 사전예약 오픈, 단골 안내 | 출고 마감일 공지 | 실적 vs 전년 |
| 추석 | 동일 | 동일 | 동일 | 동일 | 동일 |
| 연말 | 기업 선물 B2B 제안 | 병입 | 예약 | 마감 | 동일 |

→ 시스템이 시즌별 체크리스트를 일정에 자동 등록하고, 전년 판매량으로 **필요 병입량·부자재량**을 추천한다.

## 5. 체험·견학 서비스 (C-02)

| 항목 | 설계 |
|---|---|
| 프로그램 | 양조장 견학, 시음, 담금 체험, 돌배 수확 체험 (시즌) |
| 예약 기록 | 날짜, 프로그램, 인원, 요금, 연락처, 상태 |
| 자동 처리 | 예약표, 준비물·시음 수량 목록, 전날 안내 문자 초안, 체험 매출·시음 재고 차감 |
| 연계 | 체험 고객 → 고객 DB → 재구매 안내 |

## 6. CS (C-01)

| 유형 | 대응 |
|---|---|
| 배송 문의 | 송장 조회 결과 + 템플릿 답변 |
| 파손 | 사진 요청 → 재발송 → 파손 재고 처리 |
| 품질 문의 | **병입로트로 역추적** → 해당 로트 검사 기록 확인 |
| 선물·대량 | 견적 템플릿 |

답변 템플릿은 `지식층/문장은행/CS`에 저장. AI가 있으면 문장을 다듬고, 없으면 템플릿 그대로 사용.
