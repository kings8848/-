# 10. AI 운영 조직 설계 (v0.3)

> 1인 법인이지만 **조직처럼 운영**한다. 대표는 이사회 역할을 하고, AI 총괄이 일상 운영을 맡고, 전문 부서가 기능별로 일하고, 현장 작업은 사람·외주·설비에 연결된다.
> 이 문서는 08 전체 구도의 **3층(에이전트층)을 운영 조직으로 확장**한 것이다.

## 0. 한눈에 보기 — 10개 설계 영역

| # | 설계 영역 | 킹스양조장 운영 방식 | 이 문서 |
|---|---|---|---|
| 1 | 대표·경영 이사회 | 대표는 비전·자본 배분·제품 철학·중대한 예외만 결정 | 1장 |
| 2 | AI 총괄 운영 | 목표 분해 → 담당 배정 → 일정 조정 → 부서 간 인계 → 성과 확인 | 2장 |
| 3 | 전문 부서 | 9개 부서 (시장정보·상품전략·브랜드·영업·고객관리·생산계획·재무관리·품질준법·대외사업) | 3장 |
| 4 | 부서 내부 분업 | 조사·판단·제작·실행·검수 분리, 역할마다 입력·산출물·책임 | 4장 |
| 5 | 공통 회사 데이터 | 모든 결정·승인·인계를 DB에. 대화 기억에 의존하지 않음 | 5장 |
| 6 | 자동 실행 | 사건(이벤트)이 다음 업무를 시작시킴 | 6장 |
| 7 | 권한과 통제 | 예산·가격·수량·발신·수정 권한표, 벗어나면 상신 | 7장 |
| 8 | 독립 검수·복구 | 검수 → 수정·재시도 → 해결 못 한 예외만 대표에게 | 8장 |
| 9 | 성과 개선 | 지표 기반 업무 개선, 중요한 규칙 변경은 별도 통제 | 9장 |
| 10 | 현장 실행 조직 | 생산·포장·출고·설비는 작업 지시서로 사람·외주·설비에 연결, 완료 확인까지 | 10장 |

## 1. 대표 · 경영 이사회

### 1-1. 대표만 결정하는 것 (위임 불가)
| 영역 | 결정 사항 |
|---|---|
| **비전** | 미션·회사 헌법, 연간 목표, 진출 시장 (수출국 등) |
| **자본 배분** | 연간·분기 예산 총액, 설비 투자, 지원사업 신청 여부와 자부담, 차입 |
| **제품 철학** | 맛·레시피·원료 선택·블렌딩·도수, 신제품 출시, 정가, 한정판 수량 |
| **중대한 예외** | 품질 사고·회수, 큰 클레임, 법규 이슈, 권한표를 넘는 상신, 대외 공식 입장 |
| **규칙** | 권한표 변경, 중요 업무 규칙 변경 (9장) |

### 1-2. 이사회 운영 (대표 1인 + AI 총괄이 안건 준비)
| 회의 | 주기 | 안건 (AI 총괄이 상정) | 소요 |
|---|---|---|---|
| 일일 결재 | 매일 아침 | 상신 대기 건, 예외 큐 | 10~15분 |
| 주간 이사회 | 매주 월 | 지난주 성과, 이번 주 목표, 부서 간 충돌 조정 | 30분 |
| 월간 이사회 | 매월 1일 | 월 결산(H04), 예산 집행, 관제탑(정부·플랫폼·AI 간택), 개선 제안 승인 | 1시간 |
| 분기 이사회 | 분기 | 목표 재설정, 권한표·규칙 버전업, 자본 배분 | 2시간 |

외부 자문(세무사, 멘토, 동료 양조인)은 필요한 안건에 한해 참여시킨다.

## 2. AI 총괄 운영 (COO)

### 2-1. 책임 5가지
| 책임 | 하는 일 | 산출물 |
|---|---|---|
| **목표 분해** | 대표의 분기 목표 → 월 목표 → 주간 업무로 쪼갠다 | 목표 트리 (`goals`) |
| **담당 배정** | 업무마다 부서·역할·실행 주체(AI·규칙·사람·외주) 지정 | 업무 티켓 (`tasks`) |
| **일정 조정** | 시즌·생산 주기·마감·현장 여력을 고려해 일정 배치, 충돌 해결 | 주간 일정표 |
| **부서 간 인계** | 앞 부서 산출물을 다음 부서 입력으로 넘기고 누락을 막는다 | 인계 기록 |
| **성과 확인** | 완료 여부, 지표 달성, 지연 원인 확인 → 이사회 보고 | 주간·월간 성과 보고 |

### 2-2. AI 총괄이 하지 못하는 것
- 권한표를 넘는 결정 (→ 상신)
- 규칙·권한표·레시피·정가 변경
- 대표 승인 없는 대외 공식 발신
- 현장 작업을 "지시만 하고 끝내기" (완료 확인까지가 책임, 10장)

### 2-3. 하루 운영 사이클
| 시각 | AI 총괄의 일 |
|---|---|
| 07:30 | 밤사이 이벤트 처리 결과 확인, 예외 큐 정리, **일일 결재 목록** 작성 |
| 08:00 | 오늘 업무 배정 (부서별), 현장 작업 지시서 1장 발행 |
| 수시 | 이벤트 발생 → 해당 부서에 업무 생성 (6장) |
| 17:00 | 완료 확인, 미완료 사유 기록, 내일로 이월 |
| 매주 월 | 주간 이사회 안건 준비 |

### 2-4. 단계적 자율화 (현실적 도입 순서)
| 단계 | 시기 | AI 총괄의 수준 |
|---|---|---|
| 1 | 기초 (~2027.03) | **규칙 스케줄러 + 대표.** 오늘 할 일·알림을 규칙이 만들고 배정은 대표가 함 |
| 2 | 중급 (~2027.07) | **AI 총괄이 초안.** 목표 분해·배정·일정 초안을 AI가 만들고 대표가 승인 |
| 3 | 고급 (2027.08~) | **권한 범위 내 자율.** 3개월 실행 기록으로 검증된 업무부터 권한 안에서 스스로 처리 |

업무별 승격 기준: 최근 3개월 **되돌림률 5% 이하, 치명 오류 0건** → 위임 단계 한 칸 상승 (분기 이사회 승인).

| **대외사업** | 외부 자원을 가져온다 | 지원사업, 인증·인허가, 계약, 기관 협력 (O-03~O-05) | H01 | 선정률, 정산 적기 완료 |

## 4. 부서 내부 분업 — 조사 · 판단 · 제작 · 실행 · 검수

### 4-1. 역할 정의 (모든 부서 공통)
| 역할 | 하는 일 | 입력 | 산출물 | 책임 |
|---|---|---|---|---|
| **조사** | 사실·데이터·외부 정보 수집 | DB, 문서, 공고, 시장 자료 | 조사 파일 (출처 포함) | 사실의 정확성 |
| **판단** | 선택지 비교, 권한 안에서 결정 또는 상신 | 조사 파일, 권한표 | 결정 기록 또는 상신서 | 권한 준수, 근거 |
| **제작** | 문서·문구·계획·지시서를 만든다 | 결정 기록, 템플릿, 문장 은행 | 산출물 초안 | 형식·톤·기준 |
| **실행** | 발송·등록·발주·출고·지시 | 승인된 산출물 | 실행 기록 | 권한 범위 내 실행 |
| **검수** | 독립적으로 확인, 통과·되돌림 | 산출물, 기준표 | 검수 보고 (치명·주의·참고) | 오류 차단 |

**원칙:** 제작과 검수는 다른 주체가 한다. 단순한 업무는 역할을 합칠 수 있지만, **검수는 합치지 않는다.**

### 4-2. 예시 ① 상품전략 — 설 한정판 기획
| 역할 | 주체 | 입력 | 산출물 |
|---|---|---|---|
| 조사 | AI | 전년 설 판매, 재고 원액, 원가, 경쟁 선물 가격대 | `조사_설한정판.md` |
| 판단 | AI → **대표 상신** | 수량·가격 선택지 3안 (정가·한정 수량은 대표 권한) | 상신서 |
| 제작 | AI (H07) | 대표 결정 | 캠페인 계획서, 부서별 인계 목록 |
| 실행 | 영업·브랜드·생산계획 | 캠페인 계획서 | 사전예약 페이지, 병입 지시, 부자재 발주 |
| 검수 | 품질준법 (독립) | 페이지·문구·수량 | 광고 준수·수량·가격 하한선 검수 |

### 4-3. 예시 ② 고객관리 — 파손 문의
| 역할 | 주체 | 입력 | 산출물 |
|---|---|---|---|
| 조사 | 규칙 | 주문·송장·포장 사진·병입로트 | 결합 정보 |
| 판단 | AI | 권한표: 파손 재발송 1병 이하 → 자동 승인 범위 | 재발송 결정 |
| 제작 | AI (H03) | 결정 + 템플릿 | 사과·재발송 안내 |
| 실행 | 규칙 + 현장 | 안내 발송, 재발송 작업 지시 | 발송 기록, 작업 지시서 |
| 검수 | 독립 검사 | 안내문·수량 | 통과 → 발송 / 2병 이상이면 상신 |

## 5. 공통 회사 데이터 — 대화 기억에 의존하지 않는다

| 원칙 | 내용 |
|---|---|
| 단일 기준 | 제품·고객·주문·재고·원가·계약·승인은 kings.db 한 곳이 기준이다 |
| 기록이 기억이다 | AI와 나눈 대화는 기준이 아니다. 결정·승인·상신·인계는 반드시 DB에 남긴다 |
| 출처 표시 | AI 산출물의 숫자는 DB 레코드를 가리켜야 한다 |
| 기록 보존 | 수정은 덮어쓰지 않고 조정·변경 기록을 추가한다 |
| 등급 | 공개·내부·기밀·개인정보 등급에 따라 접근 주체를 제한한다 (08 문서 5장) |

### v0.3에서 추가한 회사 데이터 (schema 9장)
| 테이블 | 용도 |
|---|---|
| `departments` | 부서와 미션 |
| `goals` | 분기 → 월 → 주 목표 트리 |
| `tasks` | 업무 티켓 (부서·역할·실행 주체·입력·산출물·상태·마감) |
| `events` | 자동 실행을 시작시키는 사건 기록 |
| `authority_rules` | 권한표 |
| `approvals` | 상신과 대표 결재 |
| `exceptions` | 예외 큐 (자동 복구 실패 건) |
| `work_orders` | 현장 작업 지시서와 완료 증빙 |
| `contracts` | 계약 (공급·납품·외주·임대·보험) |
| `rule_changes` | 규칙·권한 변경 통제 기록 |
| `metrics_monthly` | 부서별 월간 성과 지표 |

## 6. 자동 실행 — 사건이 다음 업무를 시작시킨다

| 사건 (이벤트) | 감지 | 다음 업무 | 담당 부서 | 권한 밖이면 |
|---|---|---|---|---|
| **주문 발생** | 주문 수집 | 성인·주소 검증 → 로트 할당 → 출고 지시 | 영업 → 생산계획 → 현장 | 재고 부족·성인 미인증은 보류·고객 안내 |
| **재고 부족** | 안전재고 미달 | 부자재 발주 / 병입 계획 조정 | 생산계획 → 재무관리 | 예산 한도 초과 발주는 상신 |
| **문의 접수** | CS 수집 | 분류 → 정보 결합 → 답변 | 고객관리 | 품질·보상은 상신 |
| **마감 도래** | D-7·D-3 | 세무 자료, 지원사업 서류, 계약 갱신 준비 | 재무관리·대외사업 | 신청 여부·자부담은 상신 |
| **실적 변화** | 매출 ±20%, 반품률·평점 이상 | 원인 조사 → 대응안 | 시장정보 → 상품전략·영업 | 가격·수량 변경안은 상신 |
| **배송 지연** | 3일 미배송 | 고객 선안내, 택배사 확인 | 고객관리 | — |
| **저평점 후기** | 평점 3 이하 | CS 연결, 원인 확인 | 고객관리·품질준법 | 품질 문제면 상신 |
| **발효 이상** | 기준 범위 이탈 | 현장 확인 지시 | 생산계획 → 현장 | 배치 폐기 판단은 대표 |
| **AI 노출 변화** | 월간 진단 | 정정·보강 계획 | 시장정보 → 브랜드 | 공식 입장 변경은 상신 |
| **플랫폼 정책 변화** | 관제탑 | 영향 분석 → 대응안 | 시장정보 | 채널 철수·추가는 상신 |
| **캠페인 종료** | 종료 D+7 | 실적·ROI 분석 | 영업 → 재무관리 | — |

## 7. 권한과 통제 — 권한표

> 아래 수치는 **초안**이다. 대표가 분기 이사회에서 확정하고, 변경은 9장 절차를 따른다.

| 권한 | 범위 안 (자동 처리) | 범위 밖 (상신) |
|---|---|---|
| **예산** | 기존 거래처·기존 단가의 부자재·소모품 발주 건당 30만 원 이하, 월 누적 100만 원 이하 | 신규 거래처, 단가 변경, 한도 초과, 설비·광고비 |
| **가격** | 정가 그대로 판매, 승인된 캠페인의 할인율 적용 (하한선 이상) | 정가 변경, 캠페인 외 할인, 하한선 미만 |
| **수량** | 재고 범위 내 출고, 파손 재발송 1병, 예측량 120% 이내 부자재 발주 | 한정판 수량 변경, 대량 주문(B2B 20병 이상) 약속, 2병 이상 무상 제공 |
| **발신** | 배송·후기 요청 등 승인된 템플릿, 배송 문의 답변, 동의 고객에게 승인된 문구 | 신규 문구의 대량 발송, 거래처·기관·언론 발신, 공식 입장, 보상 약속 |
| **수정** | 업무 데이터의 조정 기록 추가, 콘텐츠 초안 수정 | 마스터·레시피·정가·권한표·규칙·회계 확정 자료 수정 |
| **데이터** | 공개·내부 등급의 클라우드 AI 사용 | 기밀·개인정보의 클라우드 전송 (원칙적 금지) |

### 상신서 형식 (모든 부서 공통, 1쪽)
`무엇을 / 왜 / 선택지 2~3개와 추천안 / 비용·위험 / 권한표 어느 항목을 넘는가 / 결정 기한`

## 8. 독립 검수·복구

```
실행 결과 ─▶ 독립 검수 ─┬─ 통과 ─▶ 완료 기록
                        ├─ 주의 ─▶ 자동 수정 ─▶ 재검수
                        └─ 치명 ─▶ 되돌림·재시도 (최대 2회) ─┬─ 해결 ─▶ 완료
                                                             └─ 미해결 ─▶ 예외 큐 ─▶ 대표
```

| 항목 | 기준 |
|---|---|
| 검수 주체 | 제작과 다른 AI·규칙·사람 (하네스 공통 규칙) |
| 자동 재시도 | 같은 오류 최대 2회. 3회째는 예외 큐로 |
| 복구 | 잘못 반영된 데이터는 조정 기록으로 되돌린다 (삭제하지 않는다) |
| 외부 발신 오류 | 정정 안내를 자동 초안 → 대표 승인 |
| 예외 큐 | 심각도(긴급·높음·보통), 발생 부서, 시도 내역, 추천 조치 |
| 대표 전달 | 긴급은 즉시 알림, 나머지는 일일 결재 목록 |
| 목표 | 대표에게 오는 예외 **하루 5건 이하** |

## 9. 성과 개선

### 9-1. 부서별 측정 지표 (매월 `metrics_monthly`)
| 공통 지표 | 내용 |
|---|---|
| 결과 | 매출·이익 기여, 고객 반응 (평점·재구매·응답 시간) |
| 품질 | 오류 수, 되돌림률, 치명 오류 수 |
| 속도 | 업무 처리 시간, 마감 준수율 |
| 비용 | AI 비용, 외주 비용 |
| 위임 | 3·4단계 업무 비율, 상신 건수 |

### 9-2. 개선 루프
`월간 지표 → AI 총괄이 개선 제안 (원인·대안·예상 효과) → 월간 이사회 → 시험 적용 2~4주 → 지표 비교 → 표준화 또는 원복`

### 9-3. 중요 규칙 변경 통제
| 구분 | 예 | 절차 |
|---|---|---|
| 일반 개선 | 템플릿 문구, 콘텐츠 일정, 분류 키워드 추가 | 부서 제안 → AI 총괄 승인 → 기록 |
| **중요 변경** | 권한표, 가격 하한선 공식, 출고·주세 집계 규칙, 검수 기준, 데이터 등급, 위임 단계 승격 | 상신 → 대표 승인 → 시험 환경 검증 → 버전 기록(`rule_changes`) → 적용 → **되돌리기 방법 사전 준비** |

AI는 자기 권한과 검수 기준을 스스로 바꿀 수 없다.

## 10. 현장 실행 조직 — 지시로 끝나지 않게

### 10-1. 현장 자원
| 자원 | 담당 작업 |
|---|---|
| 대표 (현장 모드) | 담금·발효 관리·증류·블렌딩·병입·검사·관능 |
| 단기 인력 (시즌) | 선물세트 조립, 포장 |
| 외주 | 라벨·박스 인쇄, 디자인, 촬영, 설비 정비, 외부 검사 기관 |
| 설비 | 발효조 센서, 증류기, 병입기 |
| 택배 | 집하·배송 |

### 10-2. 작업 지시서 흐름 (`work_orders`)
```
부서가 지시 생성 ─▶ 담당 배정 ─▶ 접수 확인 ─▶ 실행 ─▶ 완료 증빙 ─▶ 시스템 반영 ─▶ 검수
                                    │ 미접수 2시간           │ 미완료 마감 초과
                                    └──▶ 재알림 ─▶ 상신 ◀──┘
```

| 항목 | 내용 |
|---|---|
| 지시서 필수 항목 | 작업, 대상(배치·로트·주문), 수량, 기준(SOP 링크), 마감, 담당, 완료 증빙 방식 |
| 완료 증빙 | 수량 입력 + 사진 1장 (병입·포장), 측정값 (발효·증류), 외주 납품서 |
| 시스템 반영 | 증빙이 입력되어야 재고·생산·출고 상태가 바뀐다 |
| 1인 현실 반영 | 대표의 현장 작업은 **하루 1장 작업 지시서**로 묶어 발행 (오전·오후 블록) |
| 외주 연결 | 발주서·일정·납품 확인을 지시서로 관리, 지연 시 자동 독촉 초안 |
| 설비 연결 | 센서 이상 → 점검 지시 자동 생성, 정비 이력 기록 |
