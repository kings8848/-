# 총정리 — 지금까지의 작업과 검증 현황 (2026-11-17 기준)

> 구분 표시: **[확인]** 출처로 확인한 사실 · **[대표]** 대표가 제공한 정보 · **[추정]** Claude의 판단·추정·설계
> 원문 인용은 검색 결과에 나타난 발췌문이다. 웹 페이지 전문을 직접 읽은 것은 아니므로, 실행 전 원문 페이지를 열어 확인해야 한다.

---

## 1. 결론

1. **지금 있는 것은 설계다. 돌아가는 시스템은 아직 없다.** 문서 16개, 하네스 문서 5개, 데이터베이스 구조(시험 데이터로 계산 확인)는 만들었지만, 실제 주문·재고·출고를 처리하는 프로그램은 만들지 않았다.
2. **사실 근거는 일부만 확인되었다.** 12~16번 문서의 조사 내용은 출처가 있지만 대부분 기사·요약·블로그 같은 2차 자료다. 00~11번 문서의 세무·법령 내용은 출처 없이 쓴 것이 많다.
3. **Claude는 이 작업에서 6건의 오류를 냈고, 그중 5건은 대표가 먼저 지적했다** (5장).
4. **실행의 병목은 두 가지다.** ① 대표만 줄 수 있는 정보 (면허 종류, 원료 비율, 제품 사양 등) ② 세무사·관할 기관 확인. 이 두 가지 없이 실행하면 법적 위험이 있다.
5. **바로 할 수 있는 일:** 대표 정보 6가지 받기 → 세무사·기관 질의서 한 묶음 만들기 → 1단계 프로그램(주문·재고·출고) 구축.

## 6. 아직 확인하지 못한 것과 실행 전 확인 사항

### 6-1. 대표만 답할 수 있는 것
- [ ] 면허 종류: 지역특산주(전통주) 면허로 통신판매를 하고 있는가
- [ ] 제품별 원료 배합에서 농산물 비율
- [ ] 제품 사양: 원료·도수·용량·숙성 용기와 기간·가격
- [ ] 숙성 중 옹기 수와 용량, 선물세트 구성
- [ ] 현재 기록 방식(종이·엑셀), 사용 PC, 담당 세무사
- [ ] 『무기가 되는 시스템』의 계좌 5개·회의 5개, 『무기가 되는 스토리』 원전 용어

### 6-2. 세무사에게
- [ ] 주세 신고 기한, 주종별 세율, 전통주 경감 조건
- [ ] 주류 제조 장부 필수 항목, 과세표준 계산 기준(반품·시음·견본)
- [ ] 세금계산서 발행 기한, 부가세 예정고지 대상 여부
- [ ] 수출 주류 주세 처리, 선판매(분양·멤버십) 대금 처리

### 6-3. 관할 기관·부처에
- [ ] 농식품부: 제품의 청탁금지법상 농수산가공품 해당 여부 (서면 회신)
- [ ] 관할 세무서: 통신판매 승인 요건, 성인 인증 고시 개정 시행 여부, 미래 병 선판매·옹기 분양 가능 여부, 제조장 외 숙성 가능 여부
- [ ] 소재 지자체: 고향사랑기부제 답례품 공급업체 모집 공고
- [ ] 주류 광고 기준(표현·매체·경품), 맞춤 라벨·외박스 표시 범위
- [ ] 식약처 등: 오크통·병 수입 시 식품용 기구 신고, 비주류 돌배 제품 제조 허가

### 6-4. 출처 원문 확인
- [ ] 3장 원문 발췌를 원래 페이지에서 직접 확인 (검색 발췌만 본 상태)
- [ ] 네이버 쇼핑 AI 에이전트의 주류 카테고리 적용 여부
