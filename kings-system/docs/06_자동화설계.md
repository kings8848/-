## 3. AI 교체 구조 (핵심)

```
[업무 프로그램]  →  [AI 연결부 (한 곳)]  →  설정값 provider =
                                            ├ "cloud"  : Claude 등 클라우드 AI
                                            ├ "local"  : 내 PC의 Ollama + 공개 모델
                                            └ "off"    : AI 없이 템플릿만 사용
```

| 원칙 | 내용 |
|---|---|
| 연결부 단일화 | 모든 프로그램은 AI를 직접 부르지 않고 연결부 한 곳만 거친다 |
| 설정 한 줄 전환 | `config` 파일의 provider 값만 바꾸면 전체 전환 |
| 자동 대체 | 클라우드 응답 실패 시 자동으로 local → off 순서로 넘어감 |
| 템플릿 우선 | AI가 쓰는 문서도 **템플릿 + 데이터 채우기**가 기본, AI는 다듬기만 → off 상태에서도 문서가 나온다 |
| 보내지 않는 정보 | 레시피, 고객 개인정보, 원가 상세는 클라우드 AI로 보내지 않는다 (로컬 AI만 사용) |
| 모델 라이선스 | 로컬 모델은 **상업적 사용 허용 여부 확인** 후 채택 |

## 4. 백업 (3-2-1 원칙)

| 항목 | 기준 |
|---|---|
| 3 | 원본 + 백업 2개 |
| 2 | 서로 다른 매체 2종 (외장하드 + NAS 또는 암호화 클라우드) |
| 1 | 1개는 양조장 밖에 보관 (자택 등) |
| 주기 | DB 매일 밤 자동, 문서·사진 주 1회 |
| 점검 | **월 1회 백업에서 복구 테스트** |
| 보안 | 백업 파일 암호화, PC 로그인 암호, 레시피 폴더 별도 암호 |
