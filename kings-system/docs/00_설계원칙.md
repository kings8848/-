# 00. 설계 원칙

## 1. 기업 정의

| 항목 | 내용 |
|---|---|
| 형태 | 1인 법인 (대표 1인이 전 업무 수행) |
| 산업 구조 | 6차산업 = 1차(재배) × 2차(제조) × 3차(판매·서비스) |
| 1차 | 돌배, 자색옥수수 재배·수확·저장, 외부 농가 수매 |
| 2차 | 양조(담금·발효), 증류, 숙성, 블렌딩, 병입·포장 |
| 3차 | 온·오프라인 판매, B2B, 선물용 한정판, 체험·견학, 수출 |
| 대표 제품 | 봉신설주, 돌배·자색옥수수 기반 프리미엄 특산주 |

## 2. 6차산업 가치사슬과 데이터 흐름

```
[1차 재배]        [2차 제조]                                  [3차 판매·서비스]
 필지 ─ 작업일지   원료입고 ─ 담금 ─ 발효 ─ 증류 ─ 숙성 ─ 병입     주문 ─ 출고 ─ 정산 ─ CS ─ 재구매
   │                 │                                   │           │
   └─ 수확로트 ──────┘                                    └─ 병입로트 ─┘
                     
        ↓ 모든 단계가 하나의 '수불 원장'과 '로트 번호'로 연결됨 ↓

[사무] 문서·계약·지원사업·인허가   [세무] 주세·부가세·법인세·원가   [품질] 검사·관능·회수
```

**결과:** 병 하나의 라벨 번호로 *어느 밭에서, 언제 수확해, 어떤 탱크에서, 며칠 발효·숙성해, 누구에게 팔렸는지* 즉시 추적된다.
→ 품질 사고 대응, 주세 신고, 원가 계산, 브랜드 스토리(QR)가 모두 같은 데이터에서 나온다.

## 3. 8대 설계 원칙

| # | 원칙 | 의미 | 실무 기준 |
|---|---|---|---|
| 1 | **오프라인 우선** | 인터넷·외부 AI 없이 핵심 업무 100% 작동 | 데이터·프로그램 모두 내 PC에 있음 |
| 2 | **한 번 입력** | 같은 정보를 두 번 입력하지 않음 | 출고 입력 → 재고·매출·주세·고객이력 자동 반영 |
| 3 | **로트 추적** | 밭에서 고객까지 번호로 연결 | 모든 기록에 로트/배치 번호 필수 |
| 4 | **규칙 90 : AI 10** | 계산·집계·알림은 규칙 프로그램, 글쓰기·해석만 AI | AI가 없어도 약 90%는 정상 작동 |
| 5 | **AI 교체 가능** | 클라우드 AI ↔ 로컬 AI를 설정 한 줄로 전환 | 차단 시 업무 중단 0일 |
| 6 | **1인 운영 기준** | 입력 부담 최소화 | 하루 입력 15분 이내, 현장은 휴대폰·태블릿 입력 |
| 7 | **법정 기록 우선** | 세무·주류·식품 관련 의무 기록이 자동 생성 | 주류 장부·주세 집계·증빙이 버튼 하나로 출력 |
| 8 | **대표 부재 대비** | 대표가 아파도 최소 운영 가능 | 업무 매뉴얼 + 비상 연락·인수 문서 |

## 4. 시스템 4층 구조

| 층 | 구성 | 기술 (무료·오프라인) | AI 차단 시 |
|---|---|---|---|
| ① 데이터층 | 마스터(품목·거래처·고객·설비) + 기록(재배·생산·재고·판매·비용) | SQLite DB 파일 1개 | 정상 |
| ② 자동화층 | 재고 차감, 원가 계산, 번호 생성, 알림, 보고서, 신고 집계 | Python 프로그램 + 작업 스케줄러 | 정상 |
| ③ AI층 | 상세페이지·메일·서류 초안, 번역, 데이터 해석, 문서 검색 | 클라우드 AI / 로컬 AI(Ollama) | 로컬 AI로 전환 |
| ④ 지식층 | SOP, 문장 은행, 서식, 과거 서류, 사진 | 폴더 체계 + 로컬 검색 | 정상 |

입력 화면은 **엑셀(사무실)** + **웹 입력 화면(현장 휴대폰, 내부망 전용)** 두 가지로 시작한다.

## 5. 업무 영역 구분 (코드)

| 코드 | 영역 | 범위 |
|---|---|---|
| F | 1차 농업 | 필지, 재배 작업, 수확, 저장, 농가 수매 |
| P | 2차 생산 | 원료 입고 ~ 병입·포장, 설비 |
| Q | 품질 | 공정 측정, 완제품 검사, 관능, 회수 |
| I | 재고 | 수불 원장, 실사, 안전재고 |
| S | 판매 | 주문, 출고, 정산, 거래처, 수출 |
| C | 서비스 | CS, 체험, 고객 관리, 콘텐츠 |
| O | 사무 | 문서, 일정, 계약, 지원사업, 인허가 |
| T | 세무·회계 | 증빙, 신고, 원가, 결산 |

이 코드는 업무 지도(01), 자동화 목록(06), 폴더 체계에 동일하게 쓴다.
