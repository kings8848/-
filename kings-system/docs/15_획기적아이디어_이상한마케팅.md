# 15. 획기적 아이디어 — "이상한 마케팅" 연구

> 질문: 기본 말고, 사람들이 **"이건 이야기해야 해"** 하고 퍼뜨리는 아이디어는 무엇인가?
> 연구한 원형: 세스 고딘 『보랏빛 소가 온다』, Hendrick's 진 "A Most Unusual Gin", Liquid Death, 라가불린 45분 무언 영상, 닷사이 우주 발효 사케, Nudo 올리브나무 입양, 해저 숙성 와인
> [확인] 사례 조사로 확인 / [가설] 킹스 적용 판단 / (확인 필요) 실행 전 법령·허가 확인

## 0. 이상한 마케팅이 통하는 원리 (사례에서 뽑은 5가지)

| 원리 | 원형 사례 [확인] | 킹스에 주는 뜻 |
|---|---|---|
| **이야기할 만해야 퍼진다** | 고딘: 보랏빛 소 = 놀랍고, 직관에 반하고, 흥미로운 것. 퍼뜨리는 소수(재채기꾼)를 노려라 | 광고비가 아니라 **이야깃거리**를 만든다. 대상은 전통주 애호가·셰프·바텐더·지역 기자 |
| **이상함을 브랜드로 소유한다** | Hendrick's: "모두를 위한 술이 아님", 오이·장미, 가짜 빅토리아풍. 오랜 인내로 키움. 1달러 광고당 약 2.83달러 이익 추정(IPA 사례) | 킹스만의 **기묘한 의식·상징 하나**를 정해 10년 쓴다 |
| **재미가 광고비를 이긴다** | Liquid Death: 지루한 범주에서 재미로 점유율. "작은 베팅"을 빠르게 반복, 제약을 창의력으로 | 1인 기업의 제약이 오히려 무기. **작고 이상한 실험을 자주** |
| **지루함을 끝까지 밀면 화제가 된다** | 라가불린: 배우가 45분 동안 말없이 벽난로 앞에서 위스키를 마시는 영상, 3일 만에 조회 100만 회 이상 보도 | 말을 잘 못해도 된다. **말 없는 긴 영상** |
| **불가능해 보이는 숙성·원산지가 뉴스가 된다** | 닷사이: 국제우주정거장에서 발효한 사케 100ml를 약 1억 1천만 엔에 판매, 수익은 우주 개발에 기부(2026.4~5 보도) | 우주는 못 가도 **"어디서 숙성했나"를 이야기로** 만든다 |

## 1. 킹스양조장 획기적 아이디어 12

### ① 산돌배나무 입양 — "내 나무에서 열린 돌배로 빚은 술"
| 항목 | 내용 |
|---|---|
| 원형 | [확인] Nudo(이탈리아): 올리브나무를 1년 단위로 입양, 그 숲의 올리브유 3L와 나무 기록을 받는다. 수천 그루 규모, 주로 북미·유럽 고객 |
| 킹스 버전 | 산돌배나무 한 그루에 입양자 이름판 → 계절마다 **나무 리포트**(사진·개화·수확량, 시스템이 자동 생성) → 그해 그 필지 돌배로 빚은 술 받기 + 수확 체험 초대 |
| 왜 이야깃거리인가 | 술을 사는 게 아니라 **나무를 갖는다.** "나무를 선물한다"는 선물 문화 |
| 강점 | 선금 확보, 6차산업의 상징, 필지·수확 로트 데이터가 이미 있다 |
| 확인 필요 | 입양 대금과 술 인도의 구조(주세 반출 시점·통신판매), 나무 이름판의 농지 관련 사항 |
| 첫 실험 | 나무 20그루 한정 입양, 가족·단골 대상 |

### ② "무(無)AI 양조" 선언 — 역설의 이야기
| 항목 | 내용 |
|---|---|
| 아이디어 | "사무실 업무는 AI가 하고, **술은 AI 0%**". 시스템 데이터로 증명 — AI가 처리한 업무 수 vs 양조 공정의 AI 개입 0 |
| 왜 이야깃거리인가 | AI가 넘치는 2027년, **AI로 운영하는 1인 양조장이 술만은 AI를 금지**한다는 역설은 기사가 된다 [가설] |
| 연결 | 라벨 문구, 언론 보도자료, AI 자동화 강연, 진정성 브랜드 |
| 비용 | 거의 없음 (이미 가진 데이터) |
| 첫 실험 | 보도자료 1건 + 대표 인터뷰 기고 1건 |

### ③ 증류기 불멍 1시간 — 말 없는 영상
| 항목 | 내용 |
|---|---|
| 원형 | [확인] 라가불린 45분 무언 영상, 저녁 10~11시 방송을 제안한 기획 |
| 킹스 버전 | 겨울밤 증류기 불꽃, 김, 원액이 똑똑 떨어지는 소리 — **편집 없는 1시간**. 제목: "봉신설주 한 잔과 증류기 불멍 1시간". 옹기 숨소리, 돌배 수확 무편집 버전도 |
| 왜 통하나 | 말하지 않아도 되고, 휴대폰 한 대로 찍고, 겨울 내내 틀어 두는 영상이 된다 |
| 첫 실험 | 12월 증류 날 1편 촬영 → 유튜브·스마트스토어 영상 |
| 주의 | 음주 권장 표현 없이 '분위기'만 |

### ④ 킹스만의 의식 — "첫 잔은 하늘에" (고수레)
| 항목 | 내용 |
|---|---|
| 원형 | [확인] Hendrick's는 기묘한 의식·상징을 오래 소유해 브랜드가 됨 |
| 킹스 버전 | 한국 민속의 고수레(첫 음식을 자연에 먼저 바치는 풍습)를 **브랜드 의식**으로. 병목 태그에 의식 설명, 시무식·개업 고사주(14 문서 S5)와 연결 |
| 왜 이야깃거리인가 | 아무도 차지하지 않은 **한국적 의식**. 사진·영상으로 따라 하기 쉽다 |
| 연결 | 제품명에 의례 의미가 있다면 최고의 조합 (대표 확인) |

### ⑤ "AI에게 물어보세요" 광고
| 항목 | 내용 |
|---|---|
| 아이디어 | 광고에 제품을 설명하지 않는다. **"한우에 어울리는 한국 증류주가 뭔지 AI에게 물어보세요"** 한 줄만 |
| 전제 | AEO가 먼저 갖춰져서 AI가 킹스를 정확히 답해야 한다 (09·12 문서) |
| 왜 이상한가 | 광고가 고객을 경쟁자도 볼 수 있는 AI로 보낸다 — 자신감의 표시이자 화젯거리 [가설] |
| 위험 | AI가 다른 브랜드를 답하면 역효과 → **AI 간택 진단에서 3개 AI 모두 킹스가 나올 때만** 실행 |

### ⑥ 자연이 정한 한정 — "올해 돌배가 312병만 허락했다"
| 항목 | 내용 |
|---|---|
| 아이디어 | 한정 수량을 마케팅이 아니라 **수확 데이터**가 정한다. 수확량 → 가능 병수 계산식 공개 |
| 연장 | 대기 명단 고객에게 대표 손편지("올해는 드릴 수 없었습니다"), 다음 해 우선권 |
| 왜 통하나 | 가짜 희소성이 넘치는 시장에서 **진짜 희소성**은 신뢰가 된다 |

### ⑦ 실험 배치 클럽 — 실패까지 파는 연구소
| 항목 | 내용 |
|---|---|
| 아이디어 | 소량 실험 배치(다른 숙성 용기·원료 비율)를 회원에게만 공개. 회원 투표로 정식 제품 결정. 기대에 못 미친 배치도 "B면 한정판"으로 솔직하게 |
| 왜 통하나 | 연구개발이 매출이 되고, 회원은 **제품을 함께 만든 사람**이 된다 |
| 시스템 | 배치 데이터·관능 점수·투표가 DB에 쌓인다 |
| 확인 필요 | 품질 기준 통과는 필수 (실험이어도 출고 기준 동일) |

### ⑧ 한 병의 원가 공개
| 항목 | 내용 |
|---|---|
| 아이디어 | 한 병 가격을 **원료·병·숙성 손실·주세·수수료·배송·양조장 몫**으로 쪼개 공개 |
| 왜 이상한가 | 주류 업계에서 거의 하지 않는 일 [가설] |
| 효과 | 프리미엄 가격의 이유를 설명, AEO 자료, 신뢰 |
| 데이터 | 원가 시스템(T-09)에서 바로 나온다 |

### ⑨ 특이한 숙성지 한정판 + 첫 병 경매 기부
| 항목 | 내용 |
|---|---|
| 원형 | [확인] 닷사이 우주 발효 사케(수익 기부), 해외 해저 숙성 와인. [확인] 미국에서는 허가 없는 해저 숙성으로 병 압수 사례 |
| 킹스 버전 | 지자체와 협업한 **동굴·폐광·산정 숙성** 한정 배치 (관광지 콘텐츠를 원하는 지자체와 이해가 맞는다) → **1번 병 경매**, 수익은 지역 농가·산불 복구 기금 |
| 왜 뉴스가 되나 | "어디서 숙성했나" + "1번 병이 얼마에 팔렸나" + "어디에 기부했나" |
| 확인 필요 | 숙성 장소 이동의 주류 제조 허가 범위 (제조장 외 보관 규정), 경매 판매 방식 |

### ⑩ 보랏빛 소 — 자색옥수수로 "보라색"을 소유한다
| 항목 | 내용 |
|---|---|
| 아이디어 | 고딘의 '보랏빛 소'를 문자 그대로. 국내 주류에서 **보라색을 소유한 브랜드가 없다** [가설] → 자색옥수수 제품의 병·포장·이벤트를 보라색 하나로 |
| 주의 | 증류하면 색은 넘어오지 않는다. 색이 있는 제품은 주종·제조 방식이 달라진다 (확인 필요) |
| 첫 실험 | 포장·디자인만 먼저 (제품 변경 없이) |

### ⑪ 탄생목 — 아이와 함께 자라는 나무와 술
| 항목 | 내용 |
|---|---|
| 아이디어 | 아이가 태어난 해에 돌배나무 한 그루 입양(①) + 그해 빈티지 병 보관 → 아이가 성인이 된 날 부모에게 인도 |
| 왜 통하나 | 술이 아니라 **20년짜리 이야기**를 판다 |
| 대상 | 부모·조부모 (구매자는 성인) |
| 확인 필요 | 장기 보관 계약, 법령 |

### ⑫ 주문을 "거절"하는 대표의 편지
| 항목 | 내용 |
|---|---|
| 아이디어 | 한정판 대기 고객, 선물 마감 뒤 주문한 고객에게 **자동 거절 메일이 아닌 대표 이름의 편지**(AI 초안 + 대표 서명) |
| 왜 통하나 | 거절이 오히려 기억에 남는 경험이 된다. 1인 양조장이라서 진짜로 가능하다 |

## 2. 무엇부터 — 비용 × 화제성 × 1인 실행

| 순위 | 아이디어 | 비용 | 화제성 | 시작 |
|---|---|---|---|---|
| 1 | ③ 증류기 불멍 1시간 | 0원 | 중 | **12월 증류 날** |
| 2 | ② 무AI 양조 선언 | 0원 | 높음 | 12월 보도자료 |
| 3 | ⑥ 자연이 정한 한정 + ⑫ 거절 편지 | 낮음 | 중 | 설 한정판 |
| 4 | ① 산돌배나무 입양 (20그루 시험) | 낮음 | **높음** | 법령 확인 후 2027 봄 (개화기) |
| 5 | ④ 고수레 의식 | 낮음 | 중 | 시무식 고사주와 함께 |
| 6 | ⑧ 원가 공개 | 0원 | 중 | 원가 시스템 가동 후 |
| 7 | ⑦ 실험 배치 클럽 | 중 | 중 | 2027 |
| 8 | ⑤ AI에게 물어보세요 광고 | 중 | 높음 | AEO 완성 + AI 간택 진단 통과 후 |
| 9 | ⑨ 특이 숙성지 + 경매 기부 | 중 | **매우 높음** | 지자체 협의·허가 후 2027 하반기 |
| 10 | ⑩ 보랏빛 소 | 중 | 중 | 디자인부터 |
| 11 | ⑪ 탄생목 | 낮음 | 높음 | ① 운영 1년 뒤 |

**조합 제안 [가설]:** ② 무AI 선언 + ③ 불멍 영상 + ⑥ 자연 한정 → 설 시즌 하나의 이야기
"사무실은 AI가 돌리고, 술은 사람이 불 앞에서 지킨다. 올해 돌배가 허락한 만큼만."
