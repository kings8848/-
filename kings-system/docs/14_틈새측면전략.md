# 14. 틈새·측면 전략 — 대형 브랜드와 싸우지 않고 이기는 자리

> 측면 전략의 3원칙 (리스·트라우트 『마케팅 전쟁』): ① 아무도 차지하지 않은 자리에서 ② 예상 못 한 시점에 ③ 잡은 자리를 끝까지 지킨다.
> 이 문서는 "누구나 아는 방법"을 빼고, **킹스양조장이라서 이길 수 있는 자리**만 골랐다.

## 0. 세 가지 통찰 — 전략의 뿌리

### 통찰 ① 규제가 해자다 — "전통주만 들어갈 수 있는 시장"이 있다
| 시장 | 누가 못 들어오나 | 근거 |
|---|---|---|
| **온라인 프리미엄 증류주 선물** | 위스키·와인·전통주가 아닌 증류식 소주 브랜드는 온라인으로 소비자에게 팔 수 없다 | 주류 통신판매는 요건을 갖춘 전통주 제조자 중심으로 허용 [확인: 국세청 고시·유권해석 보도] |
| **고향사랑기부제 답례품** | 공급업체가 「전통주산업법」상 전통주여야 한다는 지자체 공고 사례 | [확인] 전북 공고, 위기브 전통주 답례품 운영 |
| **청탁금지법 고액 선물 한도** | 와인·양주는 일반 선물(5만 원) 기준. 원료의 50% 넘게 농산물을 쓴 **농수산가공품**은 15만 원, 명절 30만 원 | [확인] 기준 자체는 확인 / [가설] 킹스 제품의 해당 여부는 **농식품부 확인 필요** |

→ 대형 위스키·와인·비전통주 증류소는 이 세 시장에서 **법적으로 불리하거나 들어올 수 없다.** 킹스가 지역특산주(전통주) 면허를 가졌다면 이것이 가장 큰 무기다.

### 통찰 ② AI가 "작은 맞춤 주문"의 관리비를 없앤다
대형 업체가 30병짜리 맞춤 주문을 거절하는 이유는 술값이 아니라 **견적·시안·확인·출고·세금계산서 관리비**다. 킹스의 운영 시스템(위임장·하네스·자동 출고)은 이 관리비를 거의 0으로 만든다.
→ **대기업이 버리는 소량·맞춤 시장이 킹스의 시장**이 된다.

### 통찰 ③ 숙성 시간을 현금으로 바꾼다
증류주의 약점은 숙성 기간 동안 돈이 묶이는 것이다 (12 문서 상태 모형에서 현금 부족을 확인). **미래의 병을 지금 파는 구조**(분양·예약·멤버십)는 숙성 시간을 오히려 상품으로 만든다.

## 1. 틈새·측면 전략 12개

### A. 규제 해자형 (전통주라서 가능한 자리)

**S1. "위스키 대신 보낼 수 있는 한국 증류주"**
| 항목 | 내용 |
|---|---|
| 왜 비어 있나 | 온라인으로 위스키 선물을 보내려다 막히는 고객이 많은데, 그 수요를 정면으로 받는 전통주 브랜드 메시지가 드물다 [가설] |
| 킹스가 이기는 이유 | 프리미엄 증류주 + 온라인 판매 가능 + 선물 포장 |
| 실행 | 스마트스토어·자사몰·AEO에 "온라인 증류주 선물 배송", "위스키 선물 대안" 질문의 공식 답 배치. 위스키 선물 가격대(10~20만 원)와 맞춘 세트 |
| 첫 실험 (2주) | 상품 제목 A: 제품명 중심 / B: "집까지 배송되는 프리미엄 증류주 선물" → 클릭·주문 비교 |
| 확인 필요 | 비교 광고 표현 금지 범위 (특정 브랜드 비방 금지) |

**S2. 청탁금지법 기준 안의 고급 선물 (검증 우선)**
| 항목 | 내용 |
|---|---|
| 왜 비어 있나 | 공직자·교원·언론 대상 선물에서 와인·위스키는 5만 원 기준이라 고급 주류 선물이 사실상 막혀 있다 [확인: 기준] |
| 킹스가 이기는 이유 | 제품이 농수산가공품으로 인정되면 15만 원(명절 30만 원)까지 가능한 **거의 유일한 고급 주류 선택지** [가설] |
| 실행 | ① 원료 배합상 농산물 비율 확인 ② **농식품부 해당 여부 질의** ③ 인정되면 "청탁금지법 명절 기준 안" 가격 구조(14.9만·29.9만)와 확인서 첨부 |
| 첫 실험 | 질의 회신 받기 (회신 전에는 절대 이 문구를 쓰지 않는다) |
| 위험 | 해당되지 않으면 이 전략은 폐기. 잘못 표기하면 고객이 법 위반 위험을 지게 된다 |

**S3. 고향사랑기부제 답례품 + 지자체 공식 선물**
| 항목 | 내용 |
|---|---|
| 왜 비어 있나 | 답례품은 지역 공급업체로 제한되어 경쟁자가 전국이 아니라 **같은 지역 업체뿐** [확인: 운영 구조] |
| 킹스가 이기는 이유 | 지역 원료(산돌배) + 6차산업 + 프리미엄 → 지자체가 내세우기 좋은 상품 |
| 시점 | **연말(12월)에 기부가 몰린다** [가설: 연말정산 세액공제] → 지금이 신청 준비 적기 |
| 실행 | 소재 지자체 답례품 공급업체 모집 공고 확인 → 답례품 등록 신청. 기부액 구간(1만·3만·10만 원 기부 → 30% 이내 답례)에 맞춘 소용량·미니어처 구성 |
| 확장 | 지자체 공식 선물, 지역 행사 만찬주, 기관 기념품 |

### B. 맞춤·의례형 (작은 주문의 관리비를 AI가 없앤다)

**S4. 기업 소량 맞춤 한정판 (30~200병)**
| 항목 | 내용 |
|---|---|
| 왜 비어 있나 | 대형 브랜드는 소량 맞춤을 안 하고, 소규모 양조장은 관리가 버겁다 |
| 실행 | 기업명·연도·일련번호가 들어간 **외박스 슬리브·행택**(술 라벨의 법정 표시는 그대로), 대표 친필 카드, 받는 사람별 메시지 |
| 시스템 | 견적 → 시안(AI) → 확인 → 일련번호 발급 → 출고 → 세금계산서를 거래처 운영 단위(U2)가 자동 처리 |
| 가격 | 일반 선물세트 대비 맞춤 비용 포함 20~30% 높게 [가설] |
| 첫 실험 | 설 시즌, 기존 거래처·지인 기업 5곳에 제안 |
| 확인 필요 | 맞춤 표시가 라벨 표시 규정에 걸리지 않는 범위 |

**S5. 의례주 — 시무식·착공·개업 고사주, 차례주**
| 항목 | 내용 |
|---|---|
| 왜 비어 있나 | 기업의 시무식·착공식·개업식 고사, 명절 차례상은 오래된 수요인데 **프리미엄 의례주 브랜드는 거의 없다** [가설] |
| 시점 | **1월 시무식** (설보다 빠른 첫 B2B 매출), 착공·개업은 연중 |
| 실행 | "고사·의례 세트" (술 + 의례 안내 카드 + 고급 보자기), 건설·제조·부동산·개업 업종 대상 제안 |
| 브랜드 연결 | 제품명에 의례 의미가 있다면(예: 신께 올린다는 뜻) 정면으로 활용 — **대표 확인 필요** |

**S6. 인생 이벤트 기념주 — 결혼 답례, 회갑·칠순, 탄생 빈티지**
| 항목 | 내용 |
|---|---|
| 실행 | 결혼식 하객 답례 미니어처(이름·날짜 행택), 회갑·칠순 맞춤 세트, **탄생 연도 빈티지**(아이가 태어난 해 병입 → 성인이 된 뒤 개봉 예약) |
| 시스템 | 날짜 기반 재구매: 결혼기념일·생일 1년 뒤 자동 안내 (동의 고객) |
| 확인 필요 | 답례품 대량 배송 시 성인 인증·수령 방식 |

### C. 현금 선유입형 (숙성 시간을 상품으로)

**S7. 옹기 분양 — "내 이름이 걸린 옹기"**
| 항목 | 내용 |
|---|---|
| 왜 비어 있나 | 위스키 증류소의 개인 캐스크 판매는 국내에서 초기 일부 사례만 알려졌고, **전통 증류주의 옹기 분양은 사례를 찾지 못했다** [확인: 조사 범위 내] |
| 상품 | 옹기 1개분 원액 → 숙성 기간 후 병입해 인도. 이름판, 숙성 중 연 2회 **숙성 리포트**(측정 데이터·사진, 시스템이 자동 생성), 방문 시음 |
| 효과 | 선금으로 현금 확보, 최상위 고객과의 관계, 콘텐츠 |
| 확인 필요 | **미래 병의 선판매 구조가 주세·통신판매 규정상 가능한지** (판매 시점·반출 시점·대금 처리) |

**S8. 배치 우선권 멤버십**
| 항목 | 내용 |
|---|---|
| 상품 | 연간 멤버: 모든 한정 배치 우선 배정, 배치 공개 시음회, 멤버 전용 넘버 |
| 시스템 | 한정 수량 배정·결제 기한·미결제 시 다음 순번 이월을 자동 처리 |
| 확인 필요 | 선결제 방식의 법적 가능 범위 (S7과 함께 확인) |

### D. 브랜드 확장·우회형

**S9. 비주류 돌배 라인 — 규제를 피해 브랜드를 알린다**
| 항목 | 내용 |
|---|---|
| 왜 중요한가 | 주류는 광고·유통·플랫폼 제약이 크다. **비주류 제품은 어디서나 팔고 광고할 수 있다** |
| 상품 | 돌배 식초, 돌배청·시럽(카페·칵테일용), 증류 부산물 활용 제품 (원료 부산물의 식품 활용 가능 여부 확인 필요) |
| 효과 | 쿠팡·카페 납품·일반 광고로 "킹스 돌배" 인지도 → 술은 온라인 전통주 채널에서 구매 |
| 6차산업 | 부산물 활용은 지원사업·ESG 서류의 강한 근거 |
| 확인 필요 | 식품 제조 허가(별도 업종), 생산 설비 분리 |

**S10. 바텐더·칵테일 원료 + 영어권 롱테일 선점**
| 항목 | 내용 |
|---|---|
| 왜 비어 있나 | "Korean wild pear spirit" 같은 영어 질문에 답하는 공식 정보가 거의 없다 [가설] |
| 실행 | 바 전용 1L 규격·스펙 시트·시그니처 칵테일 3종, 영어 AEO 공식 정보 4종, 외국인 관광객 대상 숙소·한옥스테이 기념품 |
| 프레임 | 해외 바텐더가 아는 **배 브랜디(pear brandy)** 범주에 올라타 설명 비용을 줄인다 |
| 효과 | 수출의 전초전 (해외 바이어가 검색했을 때 이미 답이 있다) |

### E. 차별화 증폭형

**S11. 투명성 프리미엄 — 데이터를 마케팅으로**
| 항목 | 내용 |
|---|---|
| 실행 | 병마다 QR: 수확 필지·수확일·발효 곡선·숙성 일수·병입일·일련번호 (이미 DB에 있는 데이터) |
| 왜 강한가 | 경쟁자는 데이터가 없어서 따라 할 수 없다. AI 시대 "진짜의 증거"가 된다 |
| 연결 | AEO 권위, 선물 받는 사람의 경험, 언론 기사 소재 |

**S12. 한정판 드롭 — 수집가 시장**
| 항목 | 내용 |
|---|---|
| 근거 | [확인] 한정판 거래 플랫폼에 전통주 카테고리가 있고, 업계에서 신제품을 한정판 플랫폼과 동시 출시한 사례가 보도됨 |
| 실행 | 넘버링 한정판을 정해진 날 정해진 수량으로 공개 (예: 100병) |
| 확인 필요 | 플랫폼 입점 조건, 통신판매 요건 충족 여부 |
