# 11. 판매·관리 시스템 — 상품등록부터 결산까지 (v0.4)

> 현장(만들기) 다음 단계: **팔고 → 돈 받고 → 세금 내고 → 마감하는** 전 과정을 같은 기준으로 시스템화한다.
> 모든 흐름은 10 문서의 운영 조직(부서·권한·이벤트·검수·상신)을 그대로 따른다.
> (확인 필요) 표시는 법령·기관·플랫폼 규정을 확인한 뒤 확정한다. 확인 결과는 07 문서 부록 D 목록에 추가한다.

## 0. 전체 흐름도

```
[A 상품]      상품 기획 → 상품 마스터 → 채널별 등록 → 가격·재고 동기화
                   │
[B 판매]      이커머스 채널 운영 ← 광고 ← 마케팅(09 A)        B2B · 체험 · 수출(E)
                   │
[C 주문·돈]   주문 → 결제 → 출고·택배(09 D) → 정산 → 수금·미수 관리
                   │
[D 세무·결산] 세금계산서 발행·수취 → 부가세·주세 자료 → 월 결산 → 연 결산
                   │
[E 해외]      수출: 바이어 → 견적 → 계약 → 서류·통관 → 선적 → 대금
              수입: 해외 구매 → 통관 → 입고 → 원가 반영
                   │
[F 재고]      실시간 수불 → 채널 재고 동기화 → 주간 점검 → 월 실사 → 결산 재고 평가
```

| 흐름 | 주관 부서 | 협력 부서 | 하네스 | 설계 상태 (v0.3 → v0.4) |
|---|---|---|---|---|
| A 상품등록 | 상품전략 | 브랜드, 품질준법 | H02, **H11** | ❌ → ✅ |
| B 이커머스·광고 | 영업 | 브랜드, 재무관리 | H05, **H12** | △ → ✅ |
| C 결제·수금 | 재무관리 | 영업 | — (규칙) | △ → ✅ |
| D 세금계산서·결산 | 재무관리 | 대외사업 | H04 | △ → ✅ |
| E 수출·수입 | 영업(수출), 생산계획(수입) | 재무관리, 품질준법 | H09 | △ → ✅ |
| F 재고 파악 | 생산계획 | 재무관리 | — (규칙) | ✅ → 보강 |

## A. 상품등록 — 한 번 만들고, 모든 채널에 같게

### A-1. 원칙
- **상품 마스터가 원본이다.** 채널별 상품은 마스터에서 만들어지는 사본이다 (가격·사양·이미지가 채널마다 달라지지 않게).
- 등록 전 **품질준법 검수 통과**가 필수다 (주류 표시·성인 인증·광고 표현).

### A-2. 상품 마스터 (등록 전 갖춰야 할 것)
| 구분 | 항목 | 출처 |
|---|---|---|
| 기본 | SKU, 제품명, 주종, 도수, 용량, 원료·원산지, 제조사, 소재지 | `products`, `items` |
| 가격 | 정가, 채널별 판매가, B2B가, 수출가, 하한선 | `products`, 원가 |
| 표시 | 라벨 표시 사항, 보관 방법, 음주 경고 문구 (확인 필요) | 품질준법 |
| 콘텐츠 | 사람용 카피 3종, AEO 사양표, FAQ (H02) | `harness/` |
| 이미지 | 대표 이미지(실사), 상세 이미지, 라벨 근접, 선물 포장 | `70_브랜드/` |
| 물류 | 박스 규격·중량, 포장 단위, 파손 주의 | 생산계획 |
| 판매 조건 | 성인 인증, 배송 불가 지역, 1인 구매 한도(한정판), 선물 포장 옵션 | 영업 |

### A-3. 등록 절차
| 단계 | 처리 | 담당 | 권한 |
|---|---|---|---|
| 1. 등록 요청 | 신제품·한정판 확정(대표) → 등록 업무 생성 | AI 총괄 | — |
| 2. 마스터 점검 | 필수 항목 누락 검사 | 규칙 | — |
| 3. 채널 패키지 제작 | 채널별 제목 규칙·옵션·상세 구성·검색 태그 | **H11** | 3단계 |
| 4. 준수 검수 | 성인 인증 설정, 표시 사항, 금지 표현, 가격 하한선 | 품질준법 (독립) | — |
| 5. 대표 승인 | 정가·신제품은 대표 | 대표 | 상신 |
| 6. 채널 등록 | 등록 파일 업로드 또는 수기 등록 | 영업 (사람) | — |
| 7. 등록 확인 | 채널 상품번호·URL 기록, 가격·재고 대조 | 규칙 | — |

### A-4. 채널 동기화 (매일)
| 점검 | 처리 |
|---|---|
| 가격 불일치 | 채널가 ≠ 승인 가격 → 알림 (`v_listing_mismatch`) |
| 재고 | 출고 가능 재고 → 채널 재고 수량 갱신 파일 |
| 품절·재입고 | 재고 0 → 품절 처리, 병입 완료 → 재오픈 |
| 사양 변경 | 새 병입로트 도수·숙성 변경 → H02 재실행 → 채널 수정 |

### A-5. 확인 필요
- [ ] 전통주 통신판매 요건과 관할 세무서 절차
- [ ] 채널별 주류 판매 자격·성인 인증 설정 방법
- [ ] 주류 상품 표시 사항·경고 문구

## B. 이커머스·광고 — 채널을 하나의 판매 조직처럼

### B-1. 채널 구성
| 채널 | 역할 | 운영 기준 |
|---|---|---|
| 스마트스토어 | 주력 판매, 검색 유입 | 매일 주문·문의, 주 1회 상품·후기 점검 |
| 자사몰 | 고객 데이터 소유, 한정판·VIP, AEO 공식 정보 4종 | 공식 정보의 원본 |
| 기타 오픈마켓·전통주 전문몰 | 노출 확대 | 수수료·정산 주기 비교 후 선택 |
| 카톡 채널 | 동의 고객 안내 | 월 1회 + 시즌 |
| 오프라인·체험 | 사람 엔진 | 체험 예약과 현장 판매 |
| B2B | 음식점·바·기업 선물 | 거래 자격 확인 후 거래 (확인 필요) |

채널마다 `channels` 테이블에 **수수료율, 정산 주기, 성인 인증 방식**을 등록해 마진·정산 계산에 쓴다.

### B-2. 채널 운영 주기
| 주기 | 할 일 | 처리 |
|---|---|---|
| 매일 | 주문 수집, 문의, 가격·재고 동기화 | 규칙 + H03 |
| 매주 | 채널별 매출·전환·후기 점검, 노출 순위 확인 | 규칙 + 대표 |
| 매월 | 채널별 수수료 포함 순이익, 채널 추가·축소 검토 | 규칙 + H04 → 이사회 |

### B-3. 광고 운영
| 단계 | 내용 | 처리 | 권한 |
|---|---|---|---|
| 계획 | 목표(매출·ROAS), 상품, 플랫폼, 기간, 예산 | H12 초안 | **광고비 = 상신** (예산 권한 밖) |
| 소재 | 문구·이미지 (실사 기준) | H12 + H05 | — |
| 준수 검수 | 주류 광고 기준, 연령 타기팅, 플랫폼 정책 | 품질준법 | — |
| 집행 | 플랫폼 등록 | 영업 (사람) | 승인된 예산 안에서 |
| 측정 | 노출·클릭·주문·매출·ROAS 일일 수집 | 규칙 (`ad_campaigns`) | — |
| 조정 | ROAS 기준 미달 → 중단·소재 교체 제안 | H12 분석 | 예산 증액은 상신 |
| 종료 | 결과 보고, 다음 광고 기준 갱신 | H12 → 월간 이사회 | — |

**자동 규칙 (초안):** 3일 연속 ROAS가 목표의 50% 미만이면 일시 중지 제안 / 일 예산 소진율 100%면 알림.

### B-4. 확인 필요
- [ ] 주류 광고 허용 매체·표현·시간 (관련 법령·고시)
- [ ] 플랫폼별 주류 광고 정책 (검색광고, SNS 광고 연령 제한)
- [ ] 주류 B2B 직접 판매 가능 범위 (전통주 제조자의 음식점 직판 등)

## C. 결제·수금 — 들어온 돈을 하나도 놓치지 않게

### C-1. 결제 경로
| 경로 | 결제 수단 | 돈이 들어오는 방식 | 기록 |
|---|---|---|---|
| 오픈마켓 | 플랫폼 결제 | 정산 주기에 따라 수수료 차감 후 입금 | `settlements` |
| 자사몰 | 결제대행(PG): 카드·간편결제·계좌이체 | PG 정산 주기, 수수료 차감 | `settlements` |
| 방문·체험 | 카드 단말기, 현금(현금영수증) | 카드사 입금 | `payments` |
| B2B | 계좌이체 (주류 거래 대금 결제 방식 확인 필요) | 거래처 송금 | `payments` + 미수금 |
| 수출 | 외화 송금 (T/T 등) | 외화 입금 → 환전 | `export_deals` |

### C-2. 수금 흐름
```
주문 → 결제 기록 → (플랫폼) 정산 예정 계산 → 입금 확인 → 대사 일치 → 완료
                 → (B2B) 청구서·세금계산서 → 결제 기한 → 입금 확인 → 미수 시 독촉
```

| 처리 | 주기 | 담당 |
|---|---|---|
| 정산 예정액 계산 (금액 − 수수료 − 배송비) | 주문 시 | 규칙 |
| 통장 입금 내역 가져오기 (은행 엑셀) | 매주 금 | 대표 저장 → 규칙 |
| 정산 대사 (예정 vs 실제) | 매주 금 | 규칙 → 차이는 재무관리 |
| B2B 미수금 목록, 결제 기한 D-3 안내 | 매일 | 규칙 |
| 기한 경과 1차 안내 | 기한 +3일 | H03 초안 → 자동(권한 안) |
| 기한 경과 2차·거래 보류 | 기한 +14일 | **상신** |

### C-3. 결제 관련 자동 점검
- 같은 주문에 결제 2건 (중복 결제) → 예외
- 결제 없이 출고 대기 → 출고 보류
- 카드 매출 합계 vs 카드사 입금 합계 (월) → 부가세 매출 대사 자료

### D-1. 세금계산서 (전자)
| 구분 | 언제 | 처리 | 기한 (확인 필요) |
|---|---|---|---|
| **발행** (B2B 매출) | 출고 확정 시 또는 월 합계 | 규칙이 발행 목록·금액 생성 → 홈택스/발행 프로그램 발행 → 승인번호 기록 | 공급일 다음 달 10일까지 (월 합계 포함) |

## E. 수출·수입

### E-1. 수출 흐름
| 단계 | 내용 | 처리 | 권한 |
|---|---|---|---|
| 1. 시장 선정 | 국가별 수요, 규제, 지원 사업 | 시장정보 (H10) | 진출 국가 = 대표 |
| 2. 바이어 발굴 | 박람회, 수출 지원 기관, 온라인 B2B | 영업 | — |
| 3. 견적 | 수출가, 거래 조건(EXW·FOB·CIF 등), 최소 수량, 통화 | 규칙(원가·하한선) + H09 | **가격·조건 = 상신** |
| 4. 샘플 | 샘플 발송, 피드백 기록 | 영업 + 현장 | 무상 샘플 수량 권한표 |
| 5. 계약 | 계약서, 결제 조건(선금·신용장 등) | H09 초안 → 대표 | 상신 |
| 6. 국가별 준비 | 라벨(현지어·필수 표시), 수입국 등록·승인, 수입자 지정 (국가별 확인 필요) | 품질준법 + H09 | — |
| 7. 생산·포장 | 수출 로트 병입, 수출 포장 | 생산계획 → 현장 | — |
| 8. 서류 | 인보이스, 패킹리스트, 원산지증명서, 성분·검사 성적서, 수출 신고 | H09 + 관세사·포워더 | — |
| 9. 선적 | 포워더 예약, 선적, B/L 수령 | 영업 + 외주 | — |
| 10. 대금 | 외화 입금, 환전, 매출 기록 | 재무관리 | — |

## F. 재고 파악 — 언제 물어도 바로 답하는 재고

### F-1. 재고의 네 가지 숫자
| 숫자 | 뜻 | 계산 |
|---|---|---|
| 장부 재고 | 수불 원장 합계 | `v_stock` |
| 할당 재고 | 주문이 잡혀 출고 대기 중 | 출고 대기 주문 수량 |
| **출고 가능 재고** | 장부 − 할당 − 검사 미완료 | 채널에 보여줄 숫자 |
| 숙성 중 원액 | 용기별 L·순알코올 | `aging` |

### F-2. 점검 주기
| 주기 | 내용 | 처리 |
|---|---|---|
| 실시간 | 입고·투입·병입·출고 시 원장 자동 기록 | 규칙 |
| 매일 | 안전재고 미달, 채널 재고 동기화 | 규칙 |
| 매주 금 | 완제품·병·라벨·박스 **간이 점검** (상위 10품목 실물 확인) | 현장 작업 지시 |
| 매월 말 | 전 품목 실사 → 차이·사유 기록 → 조정 | 현장 + 규칙 (`inventory_counts`) |
| 분기 | 숙성 중 원액 용량·도수 실측 | 현장 |
| 연말 | 결산 재고 평가 | 재무관리 + 세무사 |

### F-3. 차이 관리
- 차이율 1% 이하: 조정 기록 후 종료
- 1~3%: 사유 조사 업무 자동 생성
- 3% 초과 또는 완제품 손실: **예외 → 대표**

```
대표의 말 → 수집함 기록 → 흐름 분류(A~F, 생산, 사무) → 기존 설계 여부 확인

```
