## 2. 전체 구도 — 7층 + 비상 동력

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 0. 관제탑      정부 규제 · 플랫폼 관문 · AI 간택 · 고객 변화 감지 (매월)        │
├─────────────────────────────────────────────────────────────────────────┤
│ 1. 입구층      고객의 AI(간택) │ 스마트스토어·자사몰 │ 카톡 채널 │ 체험·방문 │ B2B │ 수출 │
├─────────────────────────────────────────────────────────────────────────┤
│ 2. 엔진층      [사람 엔진] 얼굴·현장·체험·관계   [AI 엔진] AEO·루프·안내·제안     │
│               마케팅 ─ 세일즈 ─ 서비스                                     │
├─────────────────────────────────────────────────────────────────────────┤
│ 3. 에이전트층  대표 = 에이전트 보스 (단계 배치·검수·승인)                     │
│               리서치 · 문서 · 판매 · 서비스 에이전트                         │
├─────────────────────────────────────────────────────────────────────────┤
│ 4. 하네스층    H01~H10 AI용 업무 매뉴얼 (역할·순서·넘김·검수·실행) + 명세 6칸   │
├─────────────────────────────────────────────────────────────────────────┤
│ 5. 규칙층      주문 통합·재고·출고·원가·주세·정산·알림·백업  ← AI 없이 작동       │
├─────────────────────────────────────────────────────────────────────────┤
│ 6. 데이터층    kings.db (블랙박스) + KINGS 폴더 (지식 창고)  ← 내 PC에 있음    │
└─────────────────────────────────────────────────────────────────────────┘
  [비상 동력] AI 연결부: cloud → local → off   /   막혀도 5·6층은 그대로 돈다
```

| 층 | 누가 | 막힘에 대한 내성 |
|---|---|---|
| 0 관제탑 | 대표 (월 1회) | — |
| 1 입구층 | 플랫폼·고객 | **가장 약함** → 입구를 여러 개로 |
| 2 엔진층 | 대표 + AI | AI 엔진이 꺼져도 사람 엔진은 돈다 |
| 3 에이전트층 | AI (cloud/local) | 로컬로 전환 |
| 4 하네스층 | 문서 (내 PC) | **모델이 바뀌어도 그대로** |
| 5 규칙층 | 프로그램 (내 PC) | **완전 독립** |
| 6 데이터층 | 파일 (내 PC + 백업) | **완전 독립** |

**원칙:** 아래층일수록 내 것이고, 위층일수록 남의 것이다. 투자는 아래층부터 한다.

## 3. 고객 순환 루프 — 마케팅·매출·출고·서비스를 하나로

밀러의 퍼널은 한 방향으로 흐른다. AI 간택의 시대에는 고객이 필요할 때마다 AI에게 다시 묻기 때문에 **루프**가 돈다.

```
      ① 발견 ───────▶ ② 선택 ───────▶ ③ 구매
        ▲                                   │
        │                                   ▼
   ⑦ 추천·재발견 ◀── ⑥ 후기·재구매 ◀── ⑤ 경험 ◀── ④ 출고
```

| 단계 | 고객 행동 | 우리 시스템 | 규칙 / 하네스 | 위임 단계 | 지표 |
|---|---|---|---|---|---|
| ① 발견 | AI·검색·SNS에서 처음 봄 | AEO 공식 정보 4종, 루프 질문 답, 콘텐츠 | H02, H05, H06 | 3 | AI 노출률, 방문 수 |
| ② 선택 | 비교·문의 | 제품 사양표, FAQ, CS 답변 | H02, H03 | 3 | 문의→구매 전환 |
| ③ 구매 | 결제 (성인 인증) | 채널 주문 → 통합 | 규칙 | — | 주문 수, 객단가 |
| ④ 출고 | 기다림 | 마감 → 할당 → 포장 → 송장 → 추적 | 규칙 | — | 당일 출고율, 파손률 |
| ⑤ 경험 | 받아서 마심·선물 | 동봉 카드(배치 스토리 QR), 페어링 안내 | 규칙 + H05 | 3 | QR 접속률 |
| ⑥ 후기·재구매 | 후기 작성, 다시 삼 | 후기 요청(D+3), 재구매 안내(주기 도래) | 규칙 + H03·H07 | 3~4 | 후기율, 재구매율 |
| ⑦ 추천 | 지인에게 선물·추천, 후기가 AI에 읽힘 | 선물 재주문 안내, 후기·인용이 다음 발견으로 | H06 점검 | 3 | 추천 유입, AI 노출 변화 |

**이 루프 하나가 매출 그 자체다.** 매출 = 발견 수 × 전환율 × 객단가 × 재구매 횟수.
각 단계 지표가 자동 계기판에 올라오면, 대표는 **가장 약한 단계 하나**만 고치면 된다.

## 5. 데이터 보안 등급 — 어떤 데이터를 어떤 AI에 보내는가

| 등급 | 예 | 클라우드 AI | 로컬 AI | 규칙 프로그램 |
|---|---|---|---|---|
| **공개** | 제품 사양, 회사 소개, FAQ, 공식 입장, 공개 후기 | ○ | ○ | ○ |
| **내부** | 매출 집계(합계), 재고 수량, 캠페인 실적, 공고 분석 | ○ (합계·익명만) | ○ | ○ |
| **기밀** | 레시피·배합비, 증류 컷, 원가 상세, 거래처 단가 | ✕ | ○ | ○ |
| **개인정보** | 고객 이름·연락처·주소·구매 이력 | ✕ | 최소한만 | ○ |

모든 하네스는 시작할 때 **입력 데이터의 등급**을 확인하고, 등급에 맞는 AI로만 보낸다.
