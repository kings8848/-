# 03. 생산 설계 (1차 재배 + 2차 제조)

> 측정 주기·기준값은 **초안**이다. 실제 봉신설주 공정에 맞춰 대표가 확정한다.
> 기준값(온도·당도 범위, 컷 기준)은 레시피 테이블에 저장되어 이탈 시 자동 알림을 띄운다.

## 1. 1차 재배

### 1-1. 돌배 (다년생 과수)

| 시기(예시) | 작업 | 기록 항목 | 시스템 처리 |
|---|---|---|---|
| 겨울 | 전정, 필지 정비 | 필지, 작업시간 | 작업 이력 |
| 봄 | 시비, 개화·수정 관리 | 비료 종류·양 | 농자재 재고 차감 |
| 봄~여름 | 방제 | 약제명, 희석배수, 사용량, 살포일 | **농약 사용 이력** (출하 전 안전사용 기간 점검) |
| 여름 | 관수, 적과 | 작업시간 | — |
| 가을 | 수확·선별 | 필지, kg, 등급(상/중/가공용) | **수확로트 발행** |
| 수확 후 | 저장(냉장)·후숙 | 저장 위치, 입고일, 감량 | 원료로트로 전환 |

### 1-2. 자색옥수수 (1년생)

| 시기(예시) | 작업 | 기록 항목 | 시스템 처리 |
|---|---|---|---|
| 봄 | 파종 | 필지, 종자량, 파종일 | 재배 사이클 시작 |
| 여름 | 시비·제초·방제 | 자재, 사용량 | 농자재 차감, 농약 이력 |
| 수확기 | 수확 | kg, 상태 | 수확로트 |
| 수확 후 | 건조·탈립·저장 | 건조 전후 중량, 수분 | 건조 수율, 원료로트 |

### 1-3. 외부 농가 수매
| 기록 | 처리 |
|---|---|
| 농가(거래처), 작물, 수량, 단가, 등급 | 원료로트 발행, 매입 비용 자동 등록, 지급 예정 목록 |
| 계약재배 조건 (면적, 단가, 수량) | 계약 대비 실적 비교 |

### 1-4. 1차 성과 지표
- 필지별 수확량 (kg/㎡), 등급 비율, 연도별 비교
- 자가 원료 비중 (자가 수확 kg ÷ 전체 원료 kg) → **6차산업·지역특산주 근거 자료**

## 2. 2차 제조 공정

```
원료입고 → 검수 → 전처리 → 담금 → 발효 → 압착/여과 → 증류 → 숙성 → 블렌딩 → 병입 → 검사 → 출고가능
 P-01     Q-01    P-03     P-04   P-05    P-06       P-07   P-08   P-09    P-10   Q-03
```

### 공정별 기록 설계

| 공정 | 필수 기록 (현장 입력) | 측정 주기 | 자동 처리 | 알림 |
|---|---|---|---|---|
| 원료입고 | 품목, 수량, 공급처/수확로트, 단가 | 입고 시 | 원료로트 발행, 재고 +, 비용 등록 | 유통기한 임박 |
| 검수 | 외관, 당도, 이물 유무, 합/불 | 입고 시 | 불합격 시 재고 보류 | — |
| 전처리 | 투입량, 처리 방법, 작업시간 | 담금 전 | 작업시간 → 원가 | — |
| 담금 | 레시피, 투입 로트·수량, 용기, 가수량 | 1회 | **배치 번호 발행**, 원료 재고 −, 원료비 합산 | 레시피 대비 투입량 차이 |
| 발효 | 온도, 당도, (pH, 알코올) | 1일 1~2회 | 발효 곡선 그래프 | **기준 범위 이탈**, 측정 누락 |
| 압착/여과 | 원액량, 지게미량 | 1회 | 발효 수율 | — |
| 증류 | 투입 L·도수, 초류·본류·후류 L·도수, 시간, 전기/가스 | 회차마다 | 증류 수율, 순알코올 회수율, 에너지비 | 수율 급변 |
| 숙성 | 용기, 시작 L·도수, 월별 점검 L·도수·관능 | 월 1회 | 증발 손실(%), 숙성 기간 | 점검일, 목표 숙성일 도달 |
| 블렌딩 | 원액별 L, 가수량, 최종 도수 | 1회 | 가수량 자동 계산 | — |
| 병입 | SKU, 병 수, 용량, 도수 | 1회 | **병입로트 발행**, 원액·병·라벨·박스 차감, 완제품 + | 부자재 부족 |
| 완제품 검사 | 알코올도, (메탄올 등), 관능, 판정 | 병입로트마다 | 합격 시 출고 가능 상태 | 미검사 로트 출고 차단 |

### 자동 계산식

| 항목 | 계산 |
|---|---|
| 순알코올량 (LAA) | 용량(L) × 도수(%) ÷ 100 |
| 증류 회수율 | 본류 순알코올 ÷ 투입 순알코올 × 100 |
| 숙성 손실률 | (시작 순알코올 − 종료 순알코올) ÷ 시작 순알코올 × 100 |
| 가수량 (도수 맞추기) | 원액 L × (원액 도수 ÷ 목표 도수 − 1) — 근사값, 실측으로 최종 확인 |
| 전체 수율 | 병입 순알코올 ÷ 원료 kg (원료 1kg당 순알코올) |

## 3. 원가 계산 설계 (T-09)

### 배치 원가 구성
| 구분 | 내용 | 데이터 출처 |
|---|---|---|
| ① 원료비 | 투입 로트 × 입고 단가 (자가 수확분은 재배비 기준 단가) | batch_inputs |
| ② 부자재비 | 병, 마개, 라벨, 박스, 선물 포장 | 병입 시 차감량 × 단가 |
| ③ 에너지비 | 증류 전기·가스 사용량 × 단가 | distillations |
| ④ 직접 노무비 | 대표 작업시간 × 시간당 기준 인건비 | 공정별 작업시간 |
| ⑤ 공통비 배부 | 감가상각, 임대료, 수도, 보험 등 월 공통비 × (배치 작업시간 ÷ 월 총 작업시간) | expenses (공통) |
| ⑥ 숙성 비용 | 숙성 손실분 + 용기 상각 | aging |

### 산출물
- **병당 원가** = (①~⑥ 합계) ÷ 병입 병 수
- **SKU별 마진** = 판매가(채널별) − 병당 원가 − 채널 수수료 − 배송비 − 주세
- 한정판·선물세트는 포장비를 별도 SKU로 관리

## 4. 스마트양조 확장 (P2~P3)

| 단계 | 내용 | 비고 |
|---|---|---|
| 1 | 휴대폰 수기 입력 | 즉시 시작 |
