# 2부. 기초 — 기록이 쌓이는 회사

> **기간:** 1~4개월 (2026.12 ~ 2027.03)
> **목표:** 모든 일이 기록되고, 기록이 안전하게 보관된다.
> **도구:** 폴더, 엑셀, 종이 기록지, 외장하드 2개, 클라우드 AI
> **주 투입:** 4시간 + 매일 기록 15분

기초 단계에서는 프로그램을 만들지 않는다. 기록부터 쌓는다. 기록 없이 만든 자동화는 빈 그릇이다.

## 6장. 정리 — 폴더와 파일 이름

### 해야 할 일
- [ ] 아래 폴더 체계를 PC에 만든다
- [ ] 흩어진 파일(바탕화면, 다운로드, 휴대폰 사진, 메일 첨부)을 옮긴다
- [ ] 이후 모든 파일은 파일명 규칙을 따른다

```
KINGS/
├ 00_법인/        정관, 등기, 면허·인허가, 인증, 보험, 계약
├ 10_농업/        필지 대장, 수확 기록, 농가 계약
├ 20_생산/        SOP, 배치 기록, 설비 매뉴얼, 레시피(암호 폴더)
├ 30_품질/        검사 성적서, 관능 노트, 클레임
├ 40_판매/        주문 수집함, 출고대장, 가격표, 거래처, 시즌
├ 50_세무회계/    증빙 수집함, 월별 결산, 세무사 전달
├ 60_지원사업/    사업별 폴더 (계획서·증빙·결과)
├ 70_브랜드/      로고, 제품 사진 원본, 상세페이지, 문장 은행
├ 80_수출/        다국어 소개서, 인보이스 양식
├ 90_시스템/      마스터 엑셀, 데이터베이스, 프로그램, 설정
└ 99_백업/
```

**파일명 규칙:** `연월일_영역코드_내용_v번호`
예) `20261205_P_배치기록_B-BS-2612-01_v01.xlsx`

### 완료 기준
바탕화면과 다운로드 폴더에 업무 파일이 0개다.

## 7장. 기준 정보 — 회사의 사전 만들기

기준 정보(마스터)는 회사의 사전이다. 모든 기록은 이 사전의 단어로 쓴다.

### 해야 할 일 (`90_시스템/마스터.xlsx` 한 파일, 시트별로)

| 시트 | 항목 | 예시 |
|---|---|---|
| 품목 | 코드, 이름, 분류, 단위, 안전재고, 단가 | `RM-DB-01` 돌배, kg / `PK-BT-375` 375ml병, 개 |
| 제품(SKU) | 코드, 제품명, 주종, 용량, 도수, 소매가, 도매가 | `FG-BS-375` 봉신설주 375ml |
| 거래처 | 코드, 구분(공급처·거래처·농가·기관), 이름, 연락처 | `P-001` |
| 설비 | 코드, 종류, 용량, 위치 | `OK03` 옹기 200L |
| 필지 | 코드, 위치, 면적, 작물, 주수 | `FD-01` 돌배 |

### 번호 규칙 (외워 둘 것)

| 대상 | 형식 | 예 |
|---|---|---|
| 수확 | H-연도-작물-순번 | H-27-DB-01 |
| 원료 입고 | R-연월일-순번 | R-261205-01 |
| 담금 배치 | B-제품-연월-순번 | B-BS-2612-01 |
| 병입 (라벨 번호) | L-제품-연월일-순번 | L-BS-270310-01 |
| 주문 | O-연월일-순번 | O-270205-012 |

### 완료 기준
모든 원료·부자재·제품·설비에 코드가 있다. 코드 없는 물건이 기록에 등장하지 않는다.

## 8장. 기록 습관 — 매일 15분

### 8-1. 네 가지 기본 기록지 (엑셀)

| 기록지 | 언제 | 핵심 항목 | 위치 |
|---|---|---|---|
| **배치 기록지** | 담금~병입 | 배치번호, 투입 원료(로트·수량), 용기, 공정별 날짜·수량·도수 | `20_생산/` |
| **발효일지** | 매일 1~2회 | 배치번호, 시각, 온도, 당도, (pH, 알코올), 메모 | 배치 기록지 안의 시트 |
| **출고대장** | 출고할 때마다 | 날짜, 주문번호, 채널, 고객, 제품, 병입로트, 수량, 금액 | `40_판매/` |
| **증빙 수집** | 매주 금요일 | 카드·세금계산서·현금영수증 엑셀 다운로드 | `50_세무회계/수집함/` |

양식의 항목 목록은 [부록 B](06_부록.md)에 있다.

### 8-2. 습관을 만드는 장치

- 발효일지는 **휴대폰에 알림 2개** (아침·저녁)
- 출고대장은 **택배 상자 테이프를 붙이기 전에** 쓴다
- 증빙 수집은 **금요일 오후 고정** 15분
- 월말에는 **실사 1시간**: 창고의 병·원료·부자재를 직접 세어 엑셀과 맞춘다

### 완료 기준
30일 연속으로 기록이 빠지지 않는다.

## 9장. 지키기 — 백업과 보안

기록이 쌓이기 시작하면 그 기록을 잃는 것이 가장 큰 위험이 된다.

### 해야 할 일
- [ ] 외장하드 2개를 준비한다 (A: 양조장, B: 자택)
- [ ] 매주 금요일 `KINGS` 폴더 전체를 A에 복사한다
- [ ] 매월 말 A를 B와 바꿔 보관한다
- [ ] PC 로그인 암호를 걸고, 레시피 폴더는 별도로 암호화한다
- [ ] **복구 시험:** 외장하드에서 파일 3개를 꺼내 열어 본다

### 3-2-1 원칙
**복사본 3개**(원본 + 백업 2개), **매체 2종류**, **1개는 양조장 밖**에 둔다.

## 10장. AI 자산화 1차 — 자유로울 때 최대한 만들어 둔다

기초 단계에서 클라우드 AI는 **자산을 만드는 공장**으로 쓴다. 결과물은 반드시 파일로 저장한다.

| 자산 | 내용 | 저장 위치 | 우선 |
|---|---|---|---|
| 제조 SOP | 봉신설주·돌배·자색옥수수 제품별 공정 매뉴얼 (수치는 비워 두고 직접 기입) | `20_생산/SOP/` | ★★★ |
| 문장 은행: 브랜드 | 회사 소개 3종(30자·100자·500자), 제품별 소개, 원료 이야기 | `70_브랜드/문장은행/` | ★★★ |
| 문장 은행: 지원사업 | 회사 현황, 기술성, 시장성, 추진 계획, 기대 효과 문단 | `60_지원사업/문장은행/` | ★★★ |
| 마스터 사업계획서 | 어떤 공고에도 고쳐 쓸 수 있는 기본본 | `60_지원사업/` | ★★★ |
| 다국어 소개서 | 영·일·중 회사·제품 소개서 | `80_수출/` | ★★ |
| CS 답변 템플릿 | 배송·파손·선물·대량 주문 답변 20개 | `70_브랜드/문장은행/CS/` | ★★ |
| 업무 메일 템플릿 | 거래처 제안, 견적, 감사, 독촉 | `00_법인/서식/` | ★ |

**원칙:** AI가 만든 문서는 **반드시 직접 읽고 고친 뒤** 저장한다 (10대 원칙 9번). 레시피 수치와 고객 정보는 AI에 넣지 않는다.

## 11장. 확인 — 세무사와 기관에 물어볼 것

시스템이 자동으로 만들 서류는 처음 한 번 **정답을 확인**해야 한다. 기초 단계에서 아래 목록을 들고 세무사와 한 번 만난다.

- [ ] 주세 신고·납부 기한, 우리 제품의 주종 분류와 세율, 전통주 경감 적용 조건
- [ ] 주세 과세표준 계산 기준 (출고가 기준, 반품·시음·견본 처리)
- [ ] 주류 제조 관련 장부의 필수 항목과 서식
- [ ] 부가세 예정고지 대상 여부
- [ ] 세무사가 쓰는 회계 프로그램과 받고 싶은 자료 양식
- [ ] 자가품질검사 주기 (관할 기관)
- [ ] 6차산업(농촌융복합산업) 인증 등 활용 가능한 인증 (해당 기관)
