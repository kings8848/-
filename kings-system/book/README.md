## 이 책의 약속

1년 뒤, 킹스양조장은 다음 네 가지 상태가 된다.

1. **기록된다** — 밭에서 고객까지 모든 일이 번호로 남는다.
2. **연결된다** — 한 번 입력하면 재고·원가·매출·주세·고객 이력이 함께 움직인다.
3. **자동으로 돈다** — 업무의 약 90%를 규칙 프로그램이 처리하고, 대표는 하루 30분만 입력한다.
4. **멈추지 않는다** — 외부 AI가 막혀도, 인터넷이 끊겨도, 대표가 며칠 자리를 비워도 회사는 돌아간다.

## 이 책을 읽는 법

- **순서대로 간다.** 기초를 건너뛰고 고급으로 가면 반드시 무너진다. 자동화는 기록 위에만 선다.
- **승급 시험을 통과해야 다음 단계로 간다.** 각 부의 끝에 시험이 있다. 통과하지 못하면 그 부를 2주 더 한다.
- **5부를 책상 앞에 붙인다.** 1~4부는 '왜'와 '무엇'이고, 5부는 '이번 주에 할 일'이다.
- **상세 기술 설계는 별도 문서에 있다.** → [`../docs/`](../docs/) (업무 지도, 데이터 설계, 자동화 목록 등)
