# 4부. 고급 — 멈추지 않는 회사

> **기간:** 9~12개월 (2027.08 ~ 2027.11)
> **목표:** 외부 AI·인터넷이 없어도, 대표가 며칠 없어도 회사가 돈다.
> **도구:** AI 연결부, 로컬 AI, 지식 창고 검색, 온도 센서, 비상 카드
> **주 투입:** 5시간 (추석·수확기에는 줄인다)

고급 단계는 새로 만드는 것보다 **견디는 힘**을 만드는 단계다. 그리고 마지막에 실제로 끊어 보고 확인한다.

---

## 18장. AI 연결부 — 설정 한 줄로 갈아 끼우기

### 구조
```
[모든 업무 프로그램] → [AI 연결부 한 곳] → provider =
                                           ├ cloud : 클라우드 AI (지금)
                                           ├ local : 내 PC의 AI (제재 2단계 이상)
                                           └ off   : AI 없이 템플릿만 (비상)
```

### 규칙
| 규칙 | 내용 |
|---|---|
| 한 곳으로만 | 어떤 프로그램도 AI를 직접 부르지 않는다 |
| 자동 대체 | cloud가 응답하지 않으면 → local → off 순서로 자동으로 넘어간다 |
| 템플릿 기본 | 모든 AI 문서는 **템플릿 + 데이터 채우기**가 먼저, AI는 다듬기만 → off에서도 문서가 나온다 |
| 보내지 않는 것 | 레시피·고객정보·원가 상세는 cloud로 보내지 않고 local만 쓴다 |
| 기록 | 어떤 AI로 무엇을 만들었는지 기록한다 (지원사업 AI 사용 공개 요구에 대비) |

### AI가 쓰이는 업무 (전체 64개 중)
| 업무 | off일 때 |
|---|---|
| 상세페이지·SNS 문구 | 문장 은행 조합 |
| CS 답변 | 템플릿 그대로 |
| 지원사업 서류 | 마스터 사업계획서 + 문장 은행 |
| 업무 메일 | 메일 템플릿 |
| 수출 서류·번역 | 미리 만든 다국어 소개서 |

## 19장. 지식 창고 — 내 문서에게 묻는다

### 만드는 것
`KINGS` 폴더의 SOP, 문장 은행, 지원사업 서류, 검사 성적서, 계약서를 **내 PC 안에서 검색**하고, 로컬 AI가 찾은 내용을 요약해 준다.

| 질문 예 | 답 (출처 파일과 함께) |
|---|---|
| "작년 ○○사업에 쓴 시장성 문단 보여줘" | `60_지원사업/G-26-02/계획서_v3.hwpx` 3쪽 |
| "봉신설주 증류 SOP에서 2차 증류 주의사항은?" | `20_생산/SOP/봉신설주_v2.pdf` |
| "임대 계약 만료일 언제야?" | `00_법인/계약/…` |

**인터넷 없이 작동한다.** 클라우드에 문서를 올리지 않으니 영업비밀도 지켜진다.

## 20장. 스마트양조 — 데이터가 맛을 설명한다

| 단계 | 내용 | 시기 |
|---|---|---|
| 1 | 발효조 무선 온도 센서 → 발효일지 자동 기록 | 10개월 |
| 2 | 발효 곡선 자동 그래프 (배치끼리 겹쳐 보기) | 10개월 |
| 3 | **발효 곡선 × 관능 점수 비교**: 어떤 온도 흐름이 좋은 맛을 냈는가 | 1년 이상 데이터가 쌓인 뒤 |
| 4 | 숙성고 온습도, 숙성 기간 × 관능 비교 | 2년 차 |

센서 장비는 스마트양조·스마트공장 계열 지원사업에 포함할 수 있는지 검토한다.

## 21장. 3차 산업 확장 — 데이터로 파는 회사

| 확장 | 내용 | 데이터 출처 |
|---|---|---|
| **QR 배치 스토리** | 병의 QR을 찍으면 "이 병은 FD-01 돌배를 ○월에 수확해, 옹기에서 120일 숙성했다" | 로트 추적 |
| **한정판 넘버링** | 병입로트별 일련번호 자동 부여, 소장 등록 | 병입 기록 |
| **재구매 엔진** | 명절 4주 전 재구매 대상, 6개월 미구매 고객, 한정판 우선 안내 | 고객 구매 이력 (동의자만) |
| **체험·견학** | 예약표, 준비물, 시음 수량, 체험 고객 → 고객 DB | 체험 예약 |
| **수출** | 견적·인보이스·패킹리스트 자동, 다국어 소개서 | 제품·주문 |
| **6차산업 근거 자료** | 자가 원료 비중, 필지별 수확량, 지역 농가 매입액 | 1차 기록 |

## 22장. 차단 리허설 — 실제로 끊어 본다

**계획은 끊어 보기 전까지 가설이다.**

### 1차 리허설 (1주)
- [ ] AI 연결부를 `off`로, PC 인터넷을 끊는다 (휴대폰 입력은 내부망이라 작동)
- [ ] 평소 업무를 그대로 한다: 생산 기록, 출고, 원가, 오늘 할 일, 월 결산
- [ ] 멈춘 업무, 불편한 업무를 **리허설 일지**에 모두 적는다

### 보완 (1주)
- [ ] 멈춘 업무마다 원인 → 대책 (템플릿 추가, 프로그램 수정, 수작업 절차)

### 2차 리허설 (2주)
- [ ] 1주 차: AI `local`만 허용 / 2주 차: AI `off`
- [ ] **통과 기준: 업무 중단 0건**

※ 택배·플랫폼·홈택스처럼 원래 인터넷이 필요한 일은 "주문 엑셀을 내려받는 순간만 연결" 같은 **최소 연결 절차**로 정의해 둔다.

## 23장. 대표 부재 시스템 — 내가 없어도

1인 기업의 가장 큰 위험은 AI 제재가 아니라 **대표가 아픈 날**이다.

### 대표 부재 매뉴얼 (`00_법인/비상/`)
| 항목 | 내용 |
|---|---|
| 비상 연락망 | 가족, 세무사, 주요 거래처, 택배 기사, 도움 줄 동료 양조인 |
| 최소 운영 | 발효 중인 배치 관리법(최소 조치), 출고 중단 공지 문구, 플랫폼 휴무 설정법 |
| 접근 정보 | PC·백업 위치, 암호 보관 방식 (봉인 봉투 등) |
| 기한 업무 | 이번 달 세무·지원사업 마감 목록 (시스템이 자동 출력) |

### 시험
**3일 부재 시나리오:** 가족 또는 동료가 매뉴얼만 보고 출고 중단 공지, 발효 배치 최소 조치, 마감 목록 확인을 할 수 있는가?

## 마스터 인증 시험

| # | 시험 | 통과 기준 |
