# 3부. 중급 — 연결되고 계산되는 회사

> **기간:** 5~8개월 (2027.04 ~ 2027.07)
> **목표:** 한 번 입력하면 재고·원가·매출·주세·고객 이력이 함께 움직인다.
> **도구:** 데이터베이스(SQLite), 자동화 프로그램(Python), 휴대폰 입력 화면, 로컬 AI 장비
> **주 투입:** 6시간 (프로그램 작성은 AI와 함께)

중급의 핵심은 **엑셀 여러 개를 데이터베이스 하나로 합치는 것**이다. 그리고 지금 자유로운 AI로 **프로그램을 만들어 둔다.** 프로그램은 한 번 만들면 AI 없이 계속 돈다.

---

## 12장. 데이터베이스로 옮기기

### 왜 옮기는가
엑셀은 파일이 여러 개로 흩어진다. 같은 내용을 여러 번 적게 되고, 파일끼리 숫자가 어긋난다. 데이터베이스는 **파일 하나에 모든 기록을 두고 서로 연결한다.**

### 해야 할 일
- [ ] PC에 Python 설치 (무료)
- [ ] 데이터베이스 생성: 설계는 [`../db/schema.sql`](../db/schema.sql) (테이블 35개)
- [ ] 마스터 엑셀 → 데이터베이스로 가져오기 (프로그램이 자동으로 함)
- [ ] 기초 단계의 배치 기록·출고대장을 가져와 **과거 데이터도 연결**
- [ ] **한 달은 엑셀과 병행**한다. 두 결과가 같으면 엑셀을 끝낸다

### 수불 원장 — 중급의 심장
재고 숫자를 따로 적지 않는다. 모든 입출을 한 장부에 **+/−로 적고**, 재고는 합계로 계산한다.

| 일어난 일 | 장부에 자동 기록 |
|---|---|
| 돌배 320kg 입고 | 돌배 +320 |
| 담금에 200kg 투입 | 돌배 −200 |
| 병입 480병 | 원액 −180L, 병 −480, 라벨 −480, 완제품 +480 |
| 2병 출고 | 완제품 −2 |

## 13장. 생산·재고·원가 모듈

### 휴대폰 입력 화면 (현장용, 양조장 내부망에서만 작동)

| 화면 | 입력 (필수만) | 시스템이 하는 일 |
|---|---|---|
| 원료 입고 | 품목 선택, 수량, 공급처/수확로트, 단가 | 원료로트 번호 발행, 재고 + |
| 담금 | 레시피 선택, 투입 로트·수량, 용기 | 배치 번호 발행, 원료 재고 −, 원료비 합산 |
| 발효 측정 | 배치 선택, 온도, 당도 | 기준 범위를 벗어나면 알림 |
| 증류 | 투입 L·도수, 초류·본류·후류 L·도수, 전기·가스 | 수율, 에너지비 |
| 숙성 점검 | 용기, L, 도수, 관능 점수 | 증발 손실 |
| 병입 | 제품, 병 수, 도수 | 병입로트 번호, 부자재 −, 완제품 + |

### 병당 원가 자동 계산

| 구성 | 출처 |
|---|---|
| 원료비 | 투입 로트 × 입고 단가 |
| 부자재비 | 병·마개·라벨·박스 사용량 × 단가 |
| 에너지비 | 증류 전기·가스 |
| 노무비 | 작업시간 × 대표 시간당 기준 인건비 |
| 공통비 | 월 공통비(임대·감가상각·보험 등) × 배치 작업시간 비율 |

→ **병당 원가**와 **채널별 마진**(판매가 − 원가 − 수수료 − 배송비 − 주세)이 병입하는 순간 나온다.

## 14장. 판매·출고·주세 모듈

### 하루 출고 흐름 (대표가 하는 일은 3번)

| 순서 | 대표 | 시스템 |
|---|---|---|
| 1 | 채널별 주문 엑셀을 `주문 수집함`에 저장 | 읽기, 중복 제거, 주문 통합 |
| — | — | 성인 인증이 확인되지 않은 주문은 보류 |
| — | — | 검사 합격 로트 중 오래된 것부터 배정 (선입선출) |
| 2 | 피킹 목록 보고 포장 → **출고 확정** 버튼 | 재고 −, 반출 기록, 고객 이력 +, 택배 업로드 파일 생성 |
| 3 | 택배사에 파일 업로드, 송장 파일 저장 | 송장번호 연결, 채널 업로드 파일 생성 |

### 주세 집계 (매월 1일 자동)
전월 출고 기록 → 주종·도수·용량별 병 수·리터·순알코올·금액 집계표 → 세무사 전달.
**첫 3개월은 세무사가 직접 검토**해서 정답과 맞는지 확인한다.

## 15장. 세무 패키지와 증빙 자동 분류

### 증빙 자동 분류
- 매주 금요일 저장한 카드·홈택스 엑셀을 프로그램이 읽는다
- **분류 규칙표**(거래처·키워드 → 계정과목)로 자동 분류한다
- 분류되지 않은 건만 대표가 고른다. 고른 내용은 규칙으로 추가된다 → 갈수록 손이 덜 간다

| 규칙 예 | 계정과목 | 원가 구분 |
|---|---|---|
| 병·마개·라벨 업체 | 원재료비(부자재) | 직접 |
| 원료 농가 | 원재료비 | 직접 |
| 한전 | 전력비 | 공통 |
| 택배사 | 운반비 | 판매비 |
| 플랫폼 수수료 | 지급수수료 | 판매비 |

### 세무사 패키지 (자동 생성 폴더)
| 주기 | 내용 |
|---|---|
| 매월 | 주세 집계표, 매출·매입 목록, 급여 |
| 분기 | 부가세 자료 |
| 연 1회 | 결산 자료 (장부, 재고 평가, 지원금 내역, 고정자산) |
