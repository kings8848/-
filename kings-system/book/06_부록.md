## 부록 A. 일·주·월 점검표

### 매일 (15~30분)
- [ ] 아침: '오늘 할 일' 확인 (기초 단계에서는 달력과 메모)
- [ ] 발효 측정 기록 (아침·저녁)
- [ ] 생산 작업이 있으면 해당 기록
- [ ] 출고 기록 (상자를 봉하기 전에)
- [ ] 저녁: 누락 확인

### 매주 금요일 (30분)
- [ ] 증빙 엑셀 다운로드 → 수집함
- [ ] 플랫폼 정산 엑셀 저장
- [ ] 백업 (중급부터는 자동 백업 성공 여부만 확인)
- [ ] 5부 설계도에 이번 주 완료 표시

### 매월 말·1일 (1~2시간)
- [ ] 실사 (병·원료·부자재)
- [ ] 월 결산 보고서 확인
- [ ] 주세 자료 → 세무사
- [ ] 외장하드 A·B 교체 보관
- [ ] AI 서비스 요금·약관·공지 변경 확인 → 제재 경보 단계 판단

## 부록 B. 기록지 항목

날짜 · 필지 · 작업(전정·시비·방제·관수·제초·파종·적과·수확) · 자재 · 사용량 · 희석배수 · 작업시간 · 비고

## 부록 C. AI 제재 비상 카드

> 출력해서 PC 옆에 붙여 둔다.

| 상황 | 즉시 할 일 |
|---|---|
| 주력 AI 서비스 접속 불가 | ① AI 연결부 `provider = local` ② 로컬 AI 작동 확인 ③ 안 되면 `off` |
| 로컬 AI도 고장 | `off` — 모든 문서는 템플릿·문장 은행으로 |
| 인터넷 전체 불통 | 생산·재고·원가·일정은 정상. 주문 수집·택배·홈택스는 최소 연결 절차로 |
| PC 고장 | 백업 A에서 예비 PC로 복구 (목표 2시간) |
| 랜섬웨어 의심 | 즉시 네트워크 분리 → 외장하드 연결 금지 → 자택 백업 B로 복구 |
| 대표 부재 | `00_법인/비상/` 매뉴얼 |

**경보 단계 판단:** 0 녹색 → 1 황색(비용·제한 증가) → 2 주황(선별 차단) → 3 적색(접근 불가). 1부 2장을 참조한다.

## 부록 F. 용어

| 용어 | 뜻 |
|---|---|
| 마스터(기준 정보) | 품목·제품·거래처·설비·필지처럼 자주 바뀌지 않는 회사의 사전 |
| 로트 | 같은 조건에서 들어오거나 만들어진 묶음. 번호로 추적한다 |
| 배치 | 한 번의 담금으로 시작된 생산 단위 |
| 병입로트 | 한 번에 병에 담은 묶음. 라벨의 Batch No. |
| 수불 원장 | 모든 입·출을 +/−로 적는 단 하나의 재고 장부 |
| 선입선출 | 먼저 만든 것부터 먼저 출고한다 |
| 순알코올량 | 용량(L) × 도수(%) ÷ 100. 증류·숙성 수율 계산의 기준 |
| 클라우드 AI | 인터넷으로 외부 회사 서버에서 쓰는 AI |
| 로컬 AI | 내 PC에 설치해 인터넷 없이 쓰는 AI |
| AI 연결부 | 모든 프로그램이 AI를 부를 때 거치는 한 곳. 여기서 cloud·local·off를 바꾼다 |
| 차단 리허설 | 일부러 AI·인터넷을 끊고 회사를 운영해 보는 시험 |
| 3-2-1 백업 | 복사본 3개, 매체 2종류, 1개는 외부 보관 |
