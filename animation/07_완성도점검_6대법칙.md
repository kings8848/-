### 제1장 「깃털 한 개만!」 — 종합 ○

| 법칙 | 실제 적용 장면 | 판정 |
|---|---|---|
| 사건 | 저승사자가 세 항아리를 꺼내며 올해의 봉인을 시작한다 | ○ |
| 갈등 | "깃털 한 개만" vs "싫어" — 깃털을 받으려는 쪽과 안 주려는 쪽 | ○ |
| 웃음 | "일하기 싫어하는 검은 옷" / 저승사자가 벌렁 넘어진다 | ◎ |
| 발견 | 꽃·열매·깃털 세 항아리 규칙, 깃털은 학이 스스로 줘야 한다, 수호목에서만 받는다 | ◎ |
| 변화 | 학이 "나한테 무슨 일이 생기겠어?"를 믿는다 (예고일 뿐, 상황 변화는 약함) | △ |
| 궁금증 | 세 개를 다 못 채우면 저승사자에게 무슨 일이? | ◎ |

> 보강(변화): 장 끝에 저승사자가 두루마리를 펴 "봄 마지막 눈 = ○일" 마감을 정하는 컷 → 상황이 '평소'에서 '마감 있는 상태'로 바뀜 (**I-13** 첫 등장)

### 제2장 「마지막 눈을 멈추지 못한 날」 — 종합 ◎

| 법칙 | 실제 적용 장면 | 판정 |
|---|---|---|
| 사건 | 늦잠으로 마지막 눈을 거두지 못해 봄눈이 쏟아진다 | ◎ |
| 갈등 | 멈추라는 저승사자 vs 때를 놓친 눈 / "시간 많아" 허세 vs 학의 불안 | ◎ |
| 웃음 | "뭐 해?" "일." "네가?" "처음 보는 광경이라." | ◎ |
| 발견 | 저승사자는 얼어붙은 봉오리를 되살릴 능력이 없다 / 봉오리 안쪽이 갈색 | ◎ |
| 변화 | 저승사자 얼굴에서 웃음기가 사라진다 — 처음으로 잘못을 깨달음 | ◎ |
| 궁금증 | 저 봉오리들이 꽃을 못 피우면 어떻게 될까? | ◎ |

> 보강: **I-4** "…나도 졸았어." 한 줄 (11화 회수용)

### 제3장 「저승사자도 죽는다고?」 — 종합 ◎

| 법칙 | 실제 적용 장면 | 판정 |
|---|---|---|
| 사건 | 저승사자의 손끝에서 연기가 피어오른다 / 밤에 여인이 나타난다 | ◎ |
| 갈등 | "다른 돌배나무는?" "안 돼!" — 규칙에 반발하는 학 | ○ |
| 웃음 | "너 손에 불붙었어?" / "다른 나라 돌배나무도?" | ◎ |
| 발견 | "봉인을 완성하지 못하면 나는 사라져." | ◎ |
| 변화 | 학이 더 이상 웃지 않는다 — 장난 친구에서 걱정하는 친구로 | ◎ |
| 궁금증 | 나무에게 말을 거는 저 여인은 누구인가? | ◎ |

> 보강 불필요. 연출만: 학의 "거짓말." 웃음이 멈추는 순간에 2초 정적

### 제4장 「배꽃을 지키는 여인」 — 종합 ○

| 법칙 | 실제 적용 장면 | 판정 |
|---|---|---|
| 사건 | 여인이 날마다 나무를 돌보고, 살아 있는 봉오리 하나를 찾는다 → 첫 번째 봉인 | ◎ |
| 갈등 | 꽃이 안 필 수도 있는데 왜 기다리나 — 저승사자의 의문 (외부 위기 없음) | △ |
| 웃음 | "눈을 내리고 멈추는 능력만 있어." "쓸모가 아주 한정적이네." | ◎ |
| 발견 | "살아 있었구나." / "기다리는 사람이 있으면, 시간이 아깝지 않거든요." | ◎ |
| 변화 | 첫 번째 봉인 완성, 저승사자가 '기다리는 마음'을 처음 생각한다 | ◎ |
| 궁금증 | 꽃이 한 송이뿐이면 열매도 하나뿐 아닐까? | ○ |

> 보강(갈등): **I-5** 개화 직전 다시 찾아온 찬 밤 — 여인은 왕겨 연기, 저승사자는 눈구름 붙잡기

### 제5장 「세상에 하나 남은 돌배」 — 종합 ○

| 법칙 | 실제 적용 장면 | 판정 |
|---|---|---|
| 사건 | 하나 남은 돌배로 두 번째, 학의 깃털로 세 번째 봉인 완성 / 여인이 술독을 연다 | ◎ |
| 갈등 | "오늘은? 아직." 기다림의 지루함뿐 — 열매가 위험해지는 장면 없음 | △ |
| 웃음 | 거꾸로 매달린 학 / "정확하게 말해." "네가 제일 중요해." | ◎ |
| 발견 | 꽃도 열매도 아닌, 모든 시간이 함께 떠오르는 술의 향 | ◎ |
| 변화 | 저승사자가 처음으로 무언가를 '기억 속에 간직'한다 | ◎ |
| 궁금증 | 그 향을 다시 만나기까지 600년 — 어디서 다시 만날까? | ◎ |

> 보강(갈등): **I-6** 까치 소동 / (회수) **I-3** 1416년 첫눈 날 여인의 두 잔

### 제6장 「녹아 없어질 걸 왜 선물해?」 — 종합 ○

| 법칙 | 실제 적용 장면 | 판정 |
|---|---|---|
| 사건 | 1418년 첫눈, 태종이 정종에게 첫눈을 봉해 보낸 소식, 녹은 눈 그릇을 든 아이 | ◎ |
| 갈등 | "녹아 없어질 걸 왜 선물해?" — 학의 의문 / 다 녹아 버린 아이의 실망 | ○ |
| 웃음 | "평생? 난 오래 사는데?" / "그 얘기 그만하라고!" | ◎ |
| 발견 | "눈을 가져온 게 아니라, 첫눈이 왔다는 소식을 가져온 거니까." | ◎ |
| 변화 | 학: "없어졌는데…… 남아 있네." — 사라지는 것에 대한 생각이 바뀐다 | ◎ |
| 궁금증 | 사라지는 것과 남는 것 중 하나를 선택해야 하는 날은 언제 올까? | ◎ |

> 보강(선택): 고증 확인 후, 첫눈을 봉해 보내 상대를 속이던 놀이 풍습이 맞다면 → 학이 저승사자에게 눈 뭉치를 봉해 보내 골탕 먹이는 10초 개그 (웃음 + 고사 설명을 대사 없이)

### 제7장 「600년 동안 잊지 못한 향기」 — 종합 △ (가장 보강이 필요한 2막 구간 ①)

| 법칙 | 실제 적용 장면 | 판정 |
|---|---|---|
| 사건 | 600년 세월이 흐르고, 2006년 한 사람이 돌배나무를 심는다 | ○ |
| 갈등 | 수호목이 늙어 간다 — "이 나무가 영영 사라지면?" (두려움만 있고 부딪힘은 없음) | △ |
| 웃음 | "하나만." "싫어." "올해도 그럴 거야." / "그건 나도 보여." | ○ |
| 발견 | 누군가 다시 돌배나무를 심고 있다 | ○ |
| 변화 | 학: "너 옛날보다 말이 좀 이상해졌다. 사람처럼." | ◎ |
| 궁금증 | 저 사람은 누구이고 왜 나무를 심을까? (→ 내레이션이 상호를 바로 밝혀 궁금증이 줄어듦) | △ |

> 보강: **I-7** 사실 기반 7년의 기다림 몽타주 + 상호 언급 삭제 → 갈등(안 열리는 나무)·궁금증(누구지?) 동시 보강

### 제8장 「600년째 되는 해」 — 종합 △ (2막 구간 ②)

| 법칙 | 실제 적용 장면 | 판정 |
|---|---|---|
| 사건 | 2016년, 꽃이 거의 없는 수호목의 껍질에서 꽃무늬가 빛난다 | ○ |
| 갈등 | "그 술은 오래전에 사라졌어." vs "다시 생길 수도 있잖아." | ○ |
| 웃음 | "너는 정말 오래도 기억한다." (약함) | △ |
| 발견 | 껍질의 꽃무늬 = 첫 번째 항아리 문양 / "얼굴은 흐릿해지는데 향은 잊히지 않아." | ◎ |
| 변화 | 꽃잎이 어깨에서 빛남 — "닫혀 있던 문 하나가 조금 열린 것 같은 기분" (마음속 변화라 화면에 안 보임) | △ |
| 궁금증 | 꽃무늬와 빛나는 꽃잎은 무슨 뜻일까? (→ 원작에서 끝까지 답하지 않음) | ○ |

> 보강: **I-8** 지지대가 꺾이는 밤(사건·갈등) + **I-2** 꽃잎을 간직함(변화가 화면에 보이게, 12화 회수) + 웃음: 2013년 첫 열매를 본 학 "7년 걸렸네. 너보다 느린 게 있었어."

### 제9장 「첫눈을 기다리는 술」 — 종합 ○

| 법칙 | 실제 적용 장면 | 판정 |
|---|---|---|
| 사건 | 양조장에서 흘러나온 향을 따라가 검은 선물상자를 발견한다 | ◎ |
| 갈등 | 저승사자는 문양의 비밀을 알면서 학에게 숨긴다 | ○ |
| 웃음 | "어? 나잖아!" "나 꽤 유명한가 봐." "너는 없네?" "시끄러워." | ◎ |
| 발견 | "똑같지는 않은데…… 그 봄이 생각나." / 문양 = 학이 머물 수 있는 자리 | ◎ |
| 변화 | 그날 밤 수호목의 마지막 잎이 떨어진다 | ◎ |
| 궁금증 | 학은 문양 속 자리의 진짜 의미를 언제 알게 될까? | ◎ |

> 보강: **I-9** 설명 내레이션을 깜빡이는 문양 1컷으로 바꾸기

### 제10장 「친구에게 숨긴 비밀」 — 종합 ◎

| 법칙 | 실제 적용 장면 | 판정 |
|---|---|---|
| 사건 | 학이 빈 세 번째 항아리와 봉인 글귀를 발견한다 | ◎ |
| 갈등 | "왜 혼자 결정해?" "나는 네 깃털 항아리가 아니야." — 시리즈 최대 갈등 | ◎ |
| 웃음 | "그럼 왜 그렇게 생겼어?" "원래 이렇게 생겼거든." | ○ |
| 발견 | 학이 문양 속에 머물러야 봉인이 이어진다 / 저승사자는 알고도 숨겼다 | ◎ |
| 변화 | 학이 떠나고, 연기가 처음으로 멈추지 않는다 | ◎ |
| 궁금증 | 학은 돌아올까? 저승사자는 버틸 수 있을까? | ◎ |

### 제11장 「사라지는 저승사자」 — 종합 ○

| 법칙 | 실제 적용 장면 | 판정 |
|---|---|---|
| 사건 | 첫눈이 오지 않는 하늘, 어깨까지 사라져 가는 저승사자에게 학이 돌아온다 | ◎ |
| 갈등 | "네가 다시는 못 나올 수도 있으니까!" vs "너는 사라질 거잖아." — 서로를 위한 희생 | ◎ |
| 웃음 | "너 없으면 내가 누구를 놀려?" (웃음이 섞인 슬픔) | ○ |
| 발견 | "친구한테 선물을 주는 건…… 꼭 옆에 있어야만 가능한 거야?" (규칙 자체는 10화와 중복) | ○ |
| 변화 | "그건 내가 결정할 거야." / 저승사자가 처음으로 깃털을 달라고 하지 않는다 | ◎ |
| 궁금증 | 학은 정말 문양 속으로 들어갈까? 다시 나올 수 있을까? | ◎ |

> 보강: **I-11** 귀환 동기 + 규칙 재설명 압축 / **I-4** "그날 나도 졸았잖아."

### 제12장 「이번에는 내가 줄게」 — 종합 ◎

| 법칙 | 실제 적용 장면 | 판정 |
|---|---|---|
| 사건 | 학이 스스로 깃털을 주고 문양 속으로 들어가자 첫눈이 내린다 | ◎ |

| 웃음 | "얼른 넣어. 또 늦겠다." / "매일은 귀찮아." / "시끄러워. 잠 좀 자자." | ◎ |
| 발견 | 학은 문양 속에서도 살아 있다 — "누가 죽었대?" | ○ |
| 변화 | 600년 동안 달라던 쪽과 거절하던 쪽이 뒤바뀜 — "이번에는 내가 줄게." | ◎ |
| 궁금증 | "저걸 받으면 사람들이 웃을까?" (에필로그가 바로 답함 → 다음 시즌을 궁금하게 할 것이 약함) | △ |

> 보강: **I-12** 3일 노크 몽타주(발견을 늦춰 감정 연장) + **I-2** 새 수호목 계승(궁금증: 학은 새 나무가 첫 꽃을 피우는 봄에 나올 수 있을까?)

### 에필로그 「첫눈을 받은 사람」 — 종합 ○

| 사건 | 한 사람이 검은 선물상자를 받아 봉신설주와 이야기 카드를 꺼낸다 | ◎ |
