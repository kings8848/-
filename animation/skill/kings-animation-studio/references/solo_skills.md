# Solo Skills — 대표가 혼자 하기 위해 익힐 기술

## 1. 필요한 기술 6가지와 학습 순서

| 순서 | 기술 | 왜 필요한가 | 목표 수준 | 연습 과제 |
|---|---|---|---|---|
| 1 | **캐릭터 고정 생성** | 컷마다 학이 다르게 생기면 시청자가 떠난다 | 같은 학 10장을 연속으로 뽑기 | 캐릭터 시트 CS1~CS7 완성 |
| 2 | **이미지 → 영상 클립** | 애니메이션의 움직임 | 3~5초 클립, 움직임 1개 | 1화 C06(학 고개 돌리기) 5회 |
| 3 | **컷 편집 (CapCut 등)** | 클립·음성·음악을 하나로 | 컷 붙이기, 자막, 음량, 9:16 변환 | 1화 숏폼 40초 완성 |
| 4 | **목소리·사운드** | 웃음 타이밍은 소리가 만든다 | 대사 간격 조절, "톡, 톡" 효과음 | 1화 S5 티키타카 30초 |
| 5 | **썸네일·제목** | 클릭률 | 학 얼굴 40% + 6자 문구 | 1화 썸네일 3안 |
| 6 | **숫자 읽기** | 다음 영상을 고치는 근거 | 노출·클릭률·지속률 3개 | 숏폼 5편 결과표 |

## 2. 4주 훈련 = 1화 완성

| 주 | 배우는 것 | 결과물 |
|---|---|---|
| 1주 | 기술 1 (캐릭터 시트), 기술 5 기초 | 학·저승사자 시트 확정 |
| 2주 | 기술 1·2 (1화 27컷 이미지 + 클립) | 1화 클립 27개 |
| 3주 | 기술 3·4 (편집·녹음) | 1화 본편 4분 |
| 4주 | 기술 5·6 (업로드·분석) + 숏폼 3편 | 1화 공개, 첫 결과표 |

## 3. 주간 루틴 (공개 시작 후, 약 14~18시간)

| 요일 | 작업 | 시간 |
|---|---|---|
| 월 | 지난주 숫자 확인(모드 D) → 이번 주 본편 대본·컷 리스트(모드 A) | 2h |
| 화 | 본편 이미지 생성·수정 | 3h |
| 수 | 영상 클립 생성 + 숏폼 2편 | 3h |
| 목 | 녹음·편집 | 3h |
| 금 | 자막·썸네일·업로드 패키지(모드 C), 숏폼 2편 | 3h |
| 토 | 본편 공개, 공유, 댓글 답글 | 1h |
| 일 | 숏폼 1편 + 다음 주 숏폼 아이디어(모드 E) | 1~2h |

## 4. 막힐 때 우선순위

1. 캐릭터가 안 맞는다 → 참조 시트를 붙였는지, STYLE BLOCK을 바꾸지 않았는지 확인
2. 시간이 모자란다 → 본편 컷 수를 줄이고(정지 화면 + 카메라 이동), 숏폼 편수는 지킨다
3. 조회수가 안 오른다 → 썸네일·첫 2초부터 고친다 (내용보다 입구가 먼저)
4. 지친다 → 주 5편을 주 3편으로 줄이되 공개 요일·시각은 지킨다. 꾸준함이 편수보다 중요하다
