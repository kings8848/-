# Toolchain — 대표의 5개 도구 역할 분담

대표의 도구: **Claude · ChatGPT · Google Flow · Higgsfield · Suno** (+ 편집은 CapCut 등)

## 1. 역할표

| 도구 | 맡는 일 | 맡기지 않는 일 | 이유 |
|---|---|---|---|
| **Claude (이 스킬)** | 총괄: 대본, 6대 법칙 점검, 컷 리스트, 모든 도구용 프롬프트, 업로드 패키지, 성과 분석, 수노 가사 | 최종 이미지·영상 생성 | 세계관·규칙을 기억하고 프롬프트를 일관되게 낸다 |
| **Higgsfield** | 캐릭터 시트, 컷 키프레임 이미지, 캐릭터 고정(참조 요소), 업스케일, 캐릭터 목소리(보이스) | 긴 컷 연결 편집 | 캐릭터 일관성 관리가 핵심 강점. Claude에 연결돼 있으면 Claude가 직접 생성 가능(허락 후) |
| **Google Flow** | 키프레임 → 영상 클립 (시작·끝 프레임 지정), 장면 이어 붙이기, 환경음 | 캐릭터 디자인 새로 만들기 | Veo 기반 영상 품질. 새 캐릭터를 만들게 하면 얼굴이 바뀐다 → 항상 Higgsfield 이미지에서 시작 |
| **ChatGPT** | 교차 검토(대본 2차 의견), 영어·일본어 자막 번역 검수, 썸네일 이미지 대안 | 원작 수정, 세계관 결정 | 두 번째 눈. 결정은 Claude 기준 문서로 한다 |
| **Suno** | OST: 메인 테마(보컬), 오프닝 징글, 장면 BGM, 숏폼용 루프 | 효과음·대사 | 노래 전용 |
| CapCut 등 | 최종 편집, 자막, 음량, 9:16 변환 | — | — |

## 2. 컷 하나가 완성되는 흐름

```
① Claude: 컷 본문 + 프롬프트 (이미지용 / Flow용 / 사운드 메모)
      ↓
② Higgsfield: 키프레임 이미지 생성 (캐릭터 시트 참조 첨부) → 검수 30초
      ↓  (필요하면 끝 프레임 이미지도 1장 더)
③ Flow: Frames to Video — 시작 프레임(+끝 프레임) 넣고 Flow 프롬프트 → 클립 생성
      ↓
④ 목소리: Higgsfield 보이스로 대사 생성 (배역별 고정 목소리) 또는 녹음
      ↓
⑤ Suno: 회차 BGM / 메인 테마 (회차마다 새로 만들지 말고 OST 라이브러리에서 고름)
      ↓
⑥ CapCut: 클립 + 대사 + BGM + 효과음 + 자막 → 본편 / 숏폼
      ↓
⑦ Claude: 업로드 패키지(모드 C) → 공개 → 숫자 받아 분석(모드 D)
```

## 3. Flow용 프롬프트 형식

Flow는 시작 이미지가 화풍을 정해 주므로, 프롬프트는 **움직임·카메라·소리**에 집중한다. 영상 모델은 소리까지 만들 수 있으니 소리를 꼭 지정한다 (지정하지 않으면 원치 않는 음악·말소리가 섞일 수 있다).

```
[움직임 1개] The crane inside the silver emblem slowly turns its head and stretches one wing.
[카메라 1개] Static camera, close-up.
[스타일 유지] Keep the hand-painted 2D Korean minhwa style, brush outlines and hanji paper texture exactly as in the starting frame.
[소리] Audio: quiet room tone and a faint creak only. No music, no dialogue.
```

- 대사는 Flow로 만들지 않는다 → 목소리가 클립마다 달라진다. 대사는 ④에서 고정 목소리로 따로 만든다.
- 클립은 한 번에 몇 초 단위로 나온다. 긴 장면은 끝 프레임 → 다음 시작 프레임으로 이어 붙인다.
- 실패하면 재생성보다 프롬프트에서 움직임을 더 줄인다 (움직임이 많을수록 화풍이 깨진다).

## 4. 도구 간 일관성 규칙

| 항목 | 규칙 |
|---|---|
| 캐릭터 | 캐릭터 시트는 **Higgsfield에서 한 번 확정** → 모든 도구에 같은 이미지 파일을 참조로 쓴다 |
| 화풍 | STYLE BLOCK 문장을 Higgsfield·ChatGPT 이미지 모두 동일하게 쓴다 |
| 목소리 | 학·저승사자·내레이터 목소리 3개를 한 번 만들고 이름을 고정 (예: `WS_학_v1`) |
| 음악 | OST 라이브러리(`references/suno_ost.md` 트랙 목록)에서만 고른다 |
| 파일명 | `WS_EP03_C07_…` 규칙을 모든 도구 결과물에 적용 |

## 5. 권리·요금제 체크 (도구별)

| 도구 | 확인할 것 |
|---|---|
| Higgsfield | 상업적 이용이 가능한 플랜인지, 크레딧 잔액 |
| Google Flow | 요금제별 상업 이용 조건·워터마크(구글 AI 결과물에는 SynthID 표식) |
| ChatGPT | 이미지 상업 이용 조건 |
| Suno | **유료 플랜에서 생성한 곡만 상업 이용 가능한지** 확인. 곡마다 생성 날짜·플랜을 기록 |
| 공통 | 영상 설명란에 AI 활용 표기, 생성 기록(날짜·도구·플랜) 스프레드시트 1개로 관리 |
