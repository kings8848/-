# Suno OST — WINTER SIGNAL 사운드트랙

## 1. 음악 방향
- 악기: **해금 · 대금 · 가야금 + 피아노 · 현악** (한국 전통 + 시네마틱)
- 정서: 겨울 산의 고요함, 장난스러운 콤비, 기다림의 따뜻함
- 시그니처: 상자 노크 **"톡, 톡"** 리듬(짧은 두 음)을 모든 트랙의 모티프로 쓴다 → 시청자가 소리만 듣고 시리즈를 알아본다
- 조성 제안: 메인 테마 단조로 시작해 후렴에서 장조 느낌으로 열림

## 4. Suno 운영 규칙
1. 트랙마다 2~4개를 뽑아 가장 좋은 1개만 라이브러리에 저장 (`WS_OST_T01_v2.mp3`)
2. 메인 테마는 **1화 공개 전에 먼저 확정**해야 한다. 이후 모든 BGM이 이 곡의 분위기를 따라간다
3. 가사에 원작 문장을 쓸 때는 원작 확정본 기준 (보강안 채택 후 가사도 맞춘다)
4. 상업 이용: 유료 플랜에서 생성했는지, 생성 날짜를 기록
5. 영문판(수출용)은 T01 영어 가사 버전을 따로 만든다 — 요청 시 Claude가 번안
