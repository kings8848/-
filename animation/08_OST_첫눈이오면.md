# OST 메인 테마 「첫눈이 오면」 — Suno 입력용

> WINTER SIGNAL : 돌배꽃 주제곡 · 목표 길이 3분 내외 · 72bpm
> 쓰는 곳: 12화 엔딩, 예고편, 합본, 숏폼 하이라이트

## 1. Style (A안 · 권장: 여성 솔로)
```
Korean cinematic ballad, K-drama OST, haegeum and daegeum lead melody, gentle piano, warm string orchestra, soft gayageum plucks, two soft wooden knock sounds as a motif, slow tempo 72 bpm, warm emotional female vocal in Korean with clear diction, quiet intimate verses, soaring hopeful chorus, key change in the final chorus, winter snow atmosphere, animated film theme song
```

## 1-B. Style (B안: 남녀 듀엣 — 학 & 저승사자)
```
Korean cinematic ballad duet, K-drama OST, bright gentle female vocal and warm soft male vocal in Korean, haegeum and daegeum lead, piano and string orchestra, soft gayageum plucks, two soft wooden knock sounds as a motif, slow 72 bpm, intimate verses, harmonies in the chorus, key change in the final chorus, winter snow atmosphere, animated film theme song
```
B안은 가사에서 `[Verse 1]` → `[Verse 1: Female]`, `[Verse 2]` → `[Verse 2: Male]`, `[Bridge]` → `[Bridge: Female]`, 후렴은 `[Chorus: Duet]`로 바꿔 넣는다.

## 2. Exclude Styles (제외 스타일 칸)
```
EDM, trap, rap, hip hop, heavy drums, autotune, distorted guitar, English lyrics
```

## 5. 고르는 기준 (4개 뽑아서 1개 선택)
- [ ] 후렴 "꽃은 지지만 기다림은 남아"가 한 번 듣고 따라 불러지는가
- [ ] 인트로·아웃트로에 노크 소리(또는 비슷한 두 음)가 들리는가
- [ ] 한국어 발음이 또렷한가 (특히 "톡, 톡", "기다림", "선물이래")
- [ ] 해금·대금 소리가 실제로 들리는가 (일반 팝 발라드로 흐르지 않았는가)
- [ ] 3분 내외이고 끝이 자연스럽게 닫히는가
- [ ] 마지막 후렴이 앞 후렴보다 확실히 커지는가

## 6. 문제 생길 때
| 증상 | 고치는 법 |
|---|---|
| 국악기 소리가 안 남 | Style 맨 앞을 `Korean traditional instruments haegeum and daegeum, cinematic ballad`로 바꿔 국악기를 먼저 쓴다 |
| 너무 길다 (4분 이상) | Suno 편집 기능에서 두 번째 Pre-Chorus를 자르거나 가사에서 그 4줄을 지운다 |
| 발음이 뭉갬 | 해당 줄을 띄어쓰기로 끊는다 (예: `톡, 톡 나 여기 있어` → `톡. 톡. 나, 여기 있어`) |
| 노크 소리가 안 나옴 | 그냥 두고 편집에서 실제 노크 효과음을 얹는다 (영상 시그니처 소리와 같은 파일로) |
| 후렴이 약함 | Style에 `powerful memorable chorus hook` 추가 |
