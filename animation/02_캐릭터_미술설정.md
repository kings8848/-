# 캐릭터·미술 설정집 v0.1

> 모든 이미지·영상 생성의 **참조 기준**. 여기서 확정된 캐릭터 시트 이미지가 없으면 컷 생성을 시작하지 않는다.

## 1. 미술 톤 (시리즈 공통)

| 항목 | 기준 |
|---|---|
| 기본 스타일 | **한국 전통 채색화(민화·십장생도)의 선과 색 + 수묵 담채 배경**의 2D 애니메이션. 한지 질감이 은은히 보이는 화면 |
| 피해야 할 것 | 일본 애니풍 큰 눈, 디즈니식 3D 광택, 중국 선협풍 화려한 의상 |
| 시대별 색 | **1416~1418:** 따뜻한 담채(쪽빛·황토·연분홍) / **세월 몽타주:** 색이 점점 바래는 세피아 / **2006~2026:** 차분한 현대 톤(회청·흰색·검정·은색) |
| 계절 색 | 봄 = 연둣빛+흰 꽃 / 봄눈 = 청회색 / 가을 = 단풍 주홍·황금 / 첫눈 = 흰색+은빛+밤하늘 남색 |
| 키 컬러 | **돌배꽃 흰색 #F7F4EC · 십장생 은색 #C9CCD1 · 선물상자 검정 #1B1B1D · 구룡령 밤 남색 #22304A** |
| 빛 표현 | 봉인 빛 = 은은한 은백색 발광, 날카로운 레이저·네온 금지 |
| 화면비 | 본편 16:9 / 숏폼 9:16 |

## 2. 주요 캐릭터

### 2-1. 학 (주인공 A)

| 항목 | 설정 |
|---|---|
| 외형 | 두루미형 흰 학. 정수리 붉은 점, 목·날개 끝 검은 깃. 몸은 둥글고 작게(친근감), 다리는 가늘고 김 |
| 표정 포인트 | 한쪽 눈만 뜨기, 날개 꼭 접기(거절), 날개 으쓱하기(우쭐) |
| 문양 상태 | 상자 속에서는 **은빛 선화(라인 아트)**로 납작해짐 → 밖으로 나오면 입체 채색으로 전환 |
| 깃털 | 떨어질 때 끝이 은빛으로 반짝, 천천히 회전하며 낙하 |
| 목소리 | 젊고 새침, 말이 빠름. 감정이 클수록 말이 짧아짐 |
| 습관 대사 | "싫어." "말 많아." "야." |

### 2-2. 저승사자 (주인공 B)

| 항목 | 설정 |
|---|---|
| 외형 | 검은 도포 + 검은 갓(전통 저승사자 실루엣). **얼굴은 둥글고 순한 눈매** — 무섭지 않게. 소매 안감에 은색 눈송이 문양 |
| 소품 | 두루마리(눈의 순서), 세 항아리(품속), 갓끈에 작은 눈 결정 장식 |
| "연기" 표현 | 검은 연기가 아니라 **몸 끝이 흰 눈가루처럼 흩어지는 효과** (전연령·브랜드 톤 유지) |
| 목소리 | 30대 남성, 능청·허세, 진지할 때 낮아짐 |
| 습관 동작 | 벌렁 뒤로 넘어지기, 얼굴 감싸기, 손을 소매에 감추기 |

### 2-3. 이화곡 여인 (1416년)

| 항목 | 설정 |
|---|---|
| 외형 | 조선 초 서민 여인. 흰 무명 저고리·옥색 치마, 머릿수건, 작은 대바구니 |
| 연출 원칙 | 얼굴은 3/4 측면·뒷모습 위주, **손 클로즈업이 감정 전달 핵심** |
| 목소리 | 낮고 차분, 혼잣말 톤 |

### 2-4. 기타

| 캐릭터 | 설정 |
|---|---|
| 아이 (1418) | 7~8세, 볼 빨간 아이, 작은 사발을 품에 안음 |
| 어른 (1418) | 아이의 할머니 또는 어머니 — 따뜻한 손 |
| 나무 심는 사람 (2006·2026) | **얼굴 비노출.** 작업복·장화, 삽, 묘목. 2026년엔 양조장 작업복, 손과 뒷모습만 |
| 선물 받는 사람 (에필로그) | 성별·나이 특정 안 함. 손과 창가 실루엣 |

## 3. 핵심 소품·공간

| 대상 | 설정 |
|---|---|
| **검은 선물상자** | 실제 봉신설주 상자 기준. 무광 검정, 중앙 **육각형 은빛 십장생 문양**(해·달·구름·산·소나무·사슴·학). → **실물 상자 사진 정면·45도 2장 필수 참조** |
| 세 항아리 | 손바닥만 한 백자 항아리 3개. ① 꽃무늬 ② 둥근 열매무늬 ③ 깃털무늬. 봉인되면 무늬가 은백색으로 빛남 |
| 수호목 돌배나무 | 마을 어귀 노거수. 굵게 뒤틀린 줄기, 이끼, 넓게 퍼진 가지. 시대가 갈수록 가지가 줄고 지지대가 생김 |
| 산돌배 | 작고 둥근 사과형 야생배, 갈색 반점 껍질. 서양배 모양 금지 |
| 2006년 돌배밭 | 구룡령 산자락 비탈, 어린 묘목 줄지어 심김 |
| 1416 마을 | 강원 산간 초가 마을, 돌담, 장독대, 소나무 |
| 2026 양조장 | 작은 단층 양조장(약수매점 개조), 증류기·발효조·숙성 항아리 → **실제 양조장 사진 참조** |
| 봉신설주 병 | **실물 병 사진 참조 필수**, 라벨은 생성 시 무지 → 후편집 합성 |
