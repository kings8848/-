## 4. 컷 검수 체크리스트 (컷당 30초)

- [ ] 학: 둥근 몸, 붉은 정수리, 검은 깃끝이 캐릭터 시트와 같은가
- [ ] 저승사자: 무섭지 않은 둥근 얼굴, 갓·도포 실루엣이 같은가
- [ ] 이미지 안에 AI가 만든 글자가 없는가 (자막은 편집에서)
- [ ] 병 라벨이 무지 상태인가 → 실제 라벨 합성
- [ ] 양조장 주인·선물 받는 사람·여인의 얼굴이 노출되지 않았는가
- [ ] 산돌배가 작고 둥근 야생배 모양인가 (서양배 모양 ✖)
- [ ] 시대 색(1416 담채 / 2026 현대 톤)이 맞는가
- [ ] 화면비(본편 16:9 / 숏폼 9:16)가 맞는가
