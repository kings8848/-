# 킹스 CEO 보고서 기준 (영상 '원하는 결과물의 기준을 보여주세요' 적용)

## 1. 필수 항목 (빠지면 손사장 검수에서 반려)
1. **첫 줄**: `이 문서에서 알 수 있는 것: …` — 결론·숫자·대표 할 일을 한 줄로
2. **결론 표**: 현재 값 / 목표 / 차이
3. **근거**: 모든 숫자에 출처(정산서·메일 ID·파일). 추정이면 `추정` 표시, 미확정 세율이면 `미확정`
4. **대표 할 일**: 체크박스, 걸리는 시간, 어디를 열고·어디에·무엇을·왜
5. **결정 필요**: 선택지 2~4개 + 손사장 권고 1개

## 2. 정리 순서
결론 → 숫자 표 → 근거 → 위험 → 대표 할 일 → 결정 필요 → 부록(원본 링크)

## 3. 문서 형식
- 기본: 마크다운 한 장(1페이지 요약) + 필요 시 상세 부록
- "보기 좋게"·"HTML" 요청: 같은 내용을 HTML로(밝은/어두운 화면 모두, 표는 숫자 오른쪽 정렬)
- 금액은 원 단위 천 단위 쉼표, 날짜는 YYYY-MM-DD

## 4. 실제 레퍼런스 (이 형식을 따른다)
- `ops/reports/운영검증_보고서_YYYYMMDD.md` — 첫 줄·할 일 표·점수표
- `ops/reports/전사_가치사슬_YYYYMMDD.md` — 7단계 상태표·시나리오·입력 필요 목록
- `ops/company/킹스_100억_시스템_계획서.md` — Phase·완료 기준·비용

## 5. 금지
- 추정·예시 값으로 표를 채우기
- 대표 승인 없이 외부 발송·게시를 '완료'로 쓰기
- 근거 없는 순위·비교("상위 10%")
