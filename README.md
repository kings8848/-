# 킹스양조장 홈페이지

양양 구룡령 킹스양조장 브랜드 사이트 — **제품 설명 + 소식지** 전용.
판매는 **네이버 스마트스토어로 통일**한다 (장바구니·결제·회원가입·게시판 없음).

| 역할 | 채널 |
|---|---|
| 판매 · 성인인증 · 결제 · 배송 · 교환/반품 | 네이버 스마트스토어 |
| 봉신설주 | 와디즈 펀딩 한정 (홈페이지는 소개만) |
| 제품 설명 · 소식 · 방문 안내 | 이 홈페이지 |
| 문의 · 예약 · 알림 | 전화, 이메일, 카카오톡 채널 |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 전체 페이지 (첫 화면 / 구매 안내 / 제품 / 양조장 / 소식 / 방문 / 문의 / 하단) |
| `assets/css/style.css` | 디자인 (먹빛 + 금배주 골드 + 아이보리, 설락은 자색옥수수 보라) |
| `assets/js/main.js` | **링크 설정**, 성인 확인 팝업, 모바일 메뉴 |
| `assets/img/` | 사진 폴더 |

## 오픈 전 입력할 것

| 순위 | 항목 | 위치 |
|---|---|---|
| 1 | 스마트스토어 메인 주소 + 금배주 17·25·40도 상품 주소 | `assets/js/main.js` 의 `LINKS` |
| 2 | 카카오톡 채널 주소, 네이버 블로그 주소 | `assets/js/main.js` 의 `LINKS` |
| 3 | 주류제조면허 번호 | `index.html` 하단 `[번호 입력]` |
| 4 | 사진: 제품컷 3장, 대표 사진, 공유용 `og-image.jpg`(1200×630) | `assets/img/` |

링크가 비어 있는 버튼은 누르면 "준비 중입니다. 033-672-2888 로 문의해 주세요." 안내가 뜬다.
상품별 주소가 비어 있으면 스마트스토어 메인으로 연결된다.

## 새 소식 올리는 법

`index.html` 의 `<!-- 소식 -->` 부분에서 `<article class="news__item">` 덩어리 하나를 복사해 맨 위에 붙여넣고
날짜·분류·제목·내용만 바꾼다. 3개를 넘으면 가장 오래된 것을 지운다.

## 공개 방법 (결정 필요)

| 방법 | 비용 | 수정 | 비고 |
|---|---|---|---|
| A. GitHub Pages + soolkings.co.kr 연결 | 무료 | Claude에게 요청 또는 파일 직접 수정 | 아임웹 요금 절약. 도메인 DNS를 GitHub로 바꾸면 **아임웹 사이트는 내려감** |
| B. 아임웹 유지, 이 디자인을 참고해 아임웹에서 다시 구성 | 아임웹 요금 | 아임웹 관리자에서 직접 | 익숙한 방식 유지 |

A 진행 순서: 저장소 Settings → Pages → 브랜치 선택 → Custom domain 에 `soolkings.co.kr` 입력 →
도메인 구입처에서 DNS 를 GitHub Pages 안내값으로 변경 → HTTPS 체크.
