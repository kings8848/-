# 전후 측정 기록법 (data/time_log.csv)

| 칸 | 쓰는 법 | 예 |
|---|---|---|
| date | 측정한 날 | 2026-11-04 |
| task | 업무 이름(수작업·자동이 **같은 이름**이어야 비교됨) | 로컬푸드 정산 대사 1건 |
| mode | `수작업` 또는 `자동` | 수작업 |
| minutes | 실제 걸린 분 | 25 |
| is_estimate | 기억으로 짐작한 값이면 `Y` (점수 제외) | N |
| note | 메모 | 엑셀 열고 합계 확인·입금 통장 대조까지 |

- 수작업: 스톱워치를 켜고 정산서 1건을 엑셀·통장과 맞춰 본 시간
- 자동: `python3 ops/kings_ops.py run` 실행 후 보고서 확인까지 걸린 시간
