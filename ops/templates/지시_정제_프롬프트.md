# 지시 정제 프롬프트 (복사해서 쓰기)

**어디에**: Claude 데스크톱 → 채팅(대화 탭) 입력창
**왜**: 초안 그대로 코드 탭에 넣으면 AI가 빈칸을 마음대로 채웁니다. 먼저 정리·질문을 받고, 정리된 지시문만 실행에 넣습니다.

```
아래에 내가 작성한 지시문이 있어.
내가 원하는 목적과 핵심 의도는 유지하면서,
너가 오해 없이 정확하게 수행할 수 있도록
지시문을 구체적이고 실행 가능한 형태로 개선해줘.
그리고 너가 판단하기에 불명확한 점이 있다면
임의로 결정하지 말고 나에게 먼저 질문해줘.
질문은 한 번에 3개 이하, 선택지(번호)로 줘.

[나에 대해]
- 킹스양조장(농업회사법인 킹스) 1인 대표. 개발자가 아님 → 명령은 어디를 열고·어디에 입력하고·무엇을·왜 순서로.
- 제품: 금배주 17/25/40, 봉신설주 17. 판매: 양양로컬푸드·스마트스토어·와디즈.
- 외부로 나가는 것(고객·관공서·SNS)은 내가 승인한 뒤에만.

[지시문]
(여기에 생각나는 대로 적기)
```

정리된 지시문을 받으면 → 손사장에게 그대로 주시면 `workflow.py new`로 원문 봉인하고, 질문·답은 `ask/answer`로 기록합니다.
