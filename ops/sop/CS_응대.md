이 문서에서 알 수 있는 것: CS 응대 대리가 문의에 답변 초안을 쓰는 규칙. 초안은 자동, 발송·환불은 대표 승인, 클레임은 즉시 대표 알림.

# CS 응대 SOP v0 (대표 확인 필요)

| 문의 유형 | CS 대리 | 대표 |
|---|---|---|
| 배송 일정 | 주문현황·커머스API 확인 후 답변 초안 | 발송 승인 |
| 제품 정보(도수·용량·원료) | 라벨·품목제조보고 기준으로 초안 | 발송 승인 |
| 파손·누락·이물 | **즉시 대표 알림** + 사진·주문번호 요청 초안, 품질관리부에 배치 추적 요청 | 판단·보상 승인 |
| 환불·교환 | 정책 기준 초안 | 처리 승인 |
| 건강·효능 질문 | 답변 보류, 대표에게 넘김 | 판단 |
| 미성년 의심 | 판매 불가 안내 초안 | — |

## 대표 확인할 것
- [ ] 환불·교환 기준(기간·조건)
- [ ] 파손 보상 기준
- [ ] 응답 목표 시간(예: 24시간)
