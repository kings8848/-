이 문서에서 알 수 있는 것: 영상의 Threads·Meta 개발자 앱 연결 절차를 킹스(⑥ 브랜드·콘텐츠 담당)에 맞게 줄인 계획. 필요한 권한은 4개만 쓰고, 착수 전 확인할 것 3가지가 있습니다. **대표 결정 D-0003-5(SNS 게시 방식)가 미결이라 착수하지 않았습니다.**

# Threads 연결 계획 (⑥ 브랜드·콘텐츠)

## 영상 절차 요약
1. Instagram을 **프로페셔널 계정**으로 전환 (나중에 인스타까지 같이 운영하려고 미리 해 둠)
2. developers.facebook.com → 로그인 → **앱 만들기**
3. 앱 이름은 **영문**으로 (한글은 거부될 수 있음)
4. 이용 사례: **콘텐츠 관리 → Threads API 액세스** (+ Instagram 콘텐츠 관리)
5. 비즈니스 포트폴리오: "아직 연결 안 함" 선택 가능 → 요구 사항 → 개요 확인 → 앱 만들기
6. 이용 사례 → 권한 추가 (content_publish, read_replies, manage_replies 등)
7. 리디렉션 콜백 URL 입력 · **Threads 테스터 추가 후 초대 수락** (자사 계정만 쓰면 앱 검수를 면제받음)
8. **앱 ID는 AI가 넣고, 앱 시크릿은 CEO가 직접 .env에 넣음.** AI에게 아이디·비밀번호를 주지 않고 **승인된 경로(OAuth)로만** 접근

## 킹스 적용 — 권한은 최소로
| 권한 | 쓰나 | 이유 |
|---|:-:|---|
| threads_basic | ✅ | 필수(내 게시물 조회) |
| threads_content_publish | ✅ | 게시 — **발행 큐 승인 후에만** 호출 |
| threads_read_replies | ✅ | 고객 반응·문의 읽기 |
| threads_manage_insights | ✅ | 조회·반응 수치 → 브랜드 KPI |
| threads_manage_replies | ⏸ | 답글 자동 작성은 1단계에서 하지 않음(오답·광고 규정 위험) |
| threads_delete · keyword_search · location_tagging · mentions | ❌ | 지금 필요 없음 |

- 앱 이름 예: `Kings Brewery Ops` (영문)
- 계정 유형: Instagram **비즈니스**(판매점·브랜드). 영상의 '크리에이터'는 개인 채널용입니다.
- 시크릿·토큰은 PC의 `ops/.env`에만 둡니다. 깃허브에 올라가지 않게 막아 두었습니다.

## 착수 전 확인 3가지 (임의 진행 금지)
1. **대표 결정 D-0003-5**: 초안만 만들고 대표가 직접 게시 / 승인 후 자동 게시
2. **주류 광고 규정**: 게시물 표현·경고 문구·청소년 노출 기준을 ④ 주세·식품표시 담당이 먼저 정리 — 규정 확인 전에는 게시 기능을 켜지 않습니다
3. **콜백 URL**: 영상은 `https://localhost:3000/api/social/callback`(PC에서 웹앱 실행 전제). 킹스는 아직 웹앱이 없어, PC 작업공간 연결(Phase 1) 뒤에 정합니다

## 계획서 반영
100억 계획서 Phase 6 이후 **B구역**에 'SNS 연결'로 둡니다. 판매 데이터 연결(Phase 0~5)이 먼저입니다.
