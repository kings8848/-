# 대표님 작업공간 설정 안내 (Windows · Claude 데스크톱 앱)

> 영상 핵심: **계획 전에 작업공간부터.** 지금 킹스 자료는 ① PC 폴더(C:\...\KINGS_총괄에이전트_운영시스템) ② Google Drive ③ GitHub 저장소 세 곳에 흩어져 있습니다. 엔진과 원장이 있는 곳을 **한 폴더**로 정해야 PC의 Claude와 클라우드의 손사장이 같은 파일을 봅니다.

## 1단계. 엔진 폴더를 PC에 받기 (약 5분, 1회)

| | 내용 |
|---|---|
| 어디를 열고 | Claude 데스크톱 앱 → 왼쪽 위 **코드(`</>`) 탭** → 입력창 아래 **폴더 선택** 버튼 → `C:\` 드라이브 선택 |
| 어디에 입력하고 | 코드 탭 입력창 |
| 무엇을 입력하고 | `GitHub 저장소 kings8848/- 의 claude/pensive-wozniak-ibq62r 브랜치를 C:\KINGS 폴더로 받아줘. 받은 뒤 ops 폴더가 있는지 확인해줘.` |
| 왜 하는지 | 엔진(kings_ops.py)·원장·보고서를 PC에서 바로 열고 실행하기 위해서입니다. OneDrive 안에 두면 동기화 중 파일이 깨질 수 있어 **C:\KINGS**(OneDrive 밖)를 권합니다. |

## 2단계. 손사장(클라우드)에게 그 폴더 열어주기 (약 2분, 1회)

| | 내용 |
|---|---|
| 어디를 열고 | Claude 데스크톱 앱 → **설정** → **Claude Code** → **Remote Control** |
| 어디에 입력하고 | 폴더 추가 |
| 무엇을 입력하고 | `C:\KINGS` 선택 (역량평가 기록이 있는 `C:\Users\roser\OneDrive\Desktop\클로드코드\KINGS_총괄에이전트_운영시스템`도 필요하면 함께) |
| 왜 하는지 | 지금 손사장은 대표님 PC 파일을 못 읽습니다. 등록하면 제가 연결을 요청하고, **대표님 승인 후에만** 그 폴더를 씁니다. 배치 기록·제조일지를 PC에서 바로 읽을 수 있게 됩니다. |

## 3단계. 채팅과 코드 탭 나눠 쓰기 (습관)

| 업무 | 쓰는 곳 | 작업 폴더 |
|---|---|---|
| 정산 대사·재고·출고 경보·점수 | **코드 탭** | `C:\KINGS` |
| 지원사업 계획서·상세페이지 원고·메일 | **채팅 / Cowork** | (필요 시 Drive) |
| 영상 분석 | 채팅에 **캡처 이미지** 첨부 (YouTube 링크는 클라우드에서 차단) | — |

왜: 영상 설명처럼 코드 탭은 '작업 디렉터리'를 정해서 파일을 직접 고치고 실행합니다. 채팅은 대화와 문서용입니다.
