# 대표님 작업공간 설정 안내 (Windows · Claude 데스크톱 앱)

> 영상 핵심: **계획 전에 작업공간부터.** 지금 킹스 자료는 ① PC 폴더(C:\...\KINGS_총괄에이전트_운영시스템) ② Google Drive ③ GitHub 저장소 세 곳에 흩어져 있습니다. 엔진과 원장이 있는 곳을 **한 폴더**로 정해야 PC의 Claude와 클라우드의 손사장이 같은 파일을 봅니다.

## 0단계. PC 상태부터 확인 (약 2분, 1회)

영상: "설치되어 있는지도 모르겠습니다 → 처음부터 하나씩". 설치 여부를 모른 채 시작하면 중간에 막힙니다.

| | 내용 |
|---|---|
| 어디를 열고 | Claude 데스크톱 앱 → **코드(`</>`) 탭** |
| 어디에 입력하고 | 코드 탭 입력창 |
| 무엇을 입력하고 | `내 컴퓨터에 Python, Git, GitHub 로그인 상태가 있는지 확인만 해줘. 설치하거나 바꾸지 말고, 없는 것은 설치 방법을 한 단계씩 알려줘. 결과는 표로.` |
| 왜 하는지 | 킹스 엔진은 **Python**으로 돌고, 저장소를 받으려면 **Git**이 필요합니다(Node.js·PostgreSQL은 킹스에는 필요 없음). 엑셀 배치 양식·커머스API용으로 Python 부품 `openpyxl`, `bcrypt`, `requests`도 확인합니다. 결과 표를 손사장에게 보내 주시면 1단계를 그 상태에 맞춰 드립니다. |

## 5단계. 스마트스토어 커머스API 연결 (대표 결정, 약 15분, 1회)

| | 내용 |
|---|---|
| 어디를 열고 | 인터넷 창 → **네이버 커머스API센터**(apicenter.commerce.naver.com) → 스마트스토어 판매자 계정으로 로그인 → **애플리케이션 등록** |
| 어디에 입력하고 | 등록 화면에서 받은 **애플리케이션 ID**와 **시크릿**을 `C:\KINGS\ops\.env` 파일(메모장)에 |
| 무엇을 입력하고 | `NAVER_COMMERCE_CLIENT_ID=받은ID`  ·  `NAVER_COMMERCE_CLIENT_SECRET='받은시크릿'` (시크릿은 `$`가 있어 작은따옴표로 감쌈) |
| 왜 하는지 | 하루 1번 오는 주문현황 메일 대신 **주문 단위로 결제 후 24시간 넘은 미발송**을 잡습니다. |
| 꼭 지킬 것 | 시크릿은 **스토어 열쇠**와 같습니다. 카톡·메일·채팅에 붙여넣지 마세요. `.env`는 깃허브에 올라가지 않게 막아 두었습니다. 노출되면 커머스API센터에서 즉시 재발급. |
| 첫 실행 | 코드 탭에 `커머스API 연결기를 --days 3 으로 시험 실행하고 결과만 알려줘` → 첫 호출이 실서버 검증입니다(손사장 코드는 아직 실서버 미검증). |

## Claude Code 모드 고르기 (입력창 아래 '자동' 버튼)

| 모드 | 언제 | 킹스 권장 |
|---|---|---|
| **계획** | 새 일을 시킬 때 — 바꾸기 전에 계획서부터 받음 | ✅ 새 Phase·새 기능은 항상 여기서 시작 |
| 수동 | 바꿀 때마다 확인 | 처음 며칠 |
| 자동 / 편집 자동 수락 | 계획을 승인한 뒤 | ✅ 계획 '수락' 후 |
| 권한 무시 | 모든 권한 허용 | ❌ 쓰지 않음(외부 발송·삭제까지 묻지 않음) |

영상의 순서: ①계획 지시문 작성 → ②AI가 실현 가능하게 수정 → ③AI가 계획 → ④**대표가 확인·수정** → ⑤확인 후 실행.
막히면: **모르면 AI에게 묻고, 화면을 캡처해 보여 주기.**
