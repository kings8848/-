# 1인 기업 4층 구조 × 킹스 대조 (2026-11-04)

## 1. 층별 대조

| 층 | 글의 구조 | 킹스 현재 | 이번 보완 |
|---|---|---|---|
| 1층 창업자 | 비전·브랜드 철학·최종 승인·자본 배치 | 대표이사: 승인·양조 판단 / 자본 배치는 경영기획실 기획안 → 대표 승인 | 브랜드 철학 문서화 → `sop/브랜드_지침.md` (대표 확인 대기) |
| 2층 AI 에이전트 조직 | 기획·마케팅·**영업**·**CS**·R&D | 기획·마케팅·R&D 있음, **영업·CS 없음** | **영업·고객지원부** 신설: B2B 영업 대리(제안서 초안), CS 응대 대리(답변 초안·클레임만 대표 알림), 거래처 원장 대리(코드) |
| 3층 자동화 파이프라인 | n8n·Make·API, 24시간 데이터 흐름 | 엔진이 따로따로, 사람이 실행해야 돎 | `ops/pipeline.py` — 한 줄로 수집→대사→가치사슬→경보→업무→아침 보고. PC 스케줄러에 걸면 매일 자동(비용 0, n8n 불필요) |
| 4층 글로벌 인프라 | 결제·웹·글로벌 채널 | 스마트스토어·로컬푸드·와디즈(플랫폼 결제) | 커머스API 연결기 준비 완료, 자사몰·수출은 S2~S3 |

## 2. 운영 원칙 대조

| 원칙 | 킹스 구현 |
|---|---|
| 대표는 작업자가 아니라 감독관 | 대표 일은 승인·답변·양조뿐. 아침 보고 첫 줄에 '대표 확인 필요 N건' |
| 모든 업무 SOP 문서화 → AI의 뇌 | `ops/sop/README.md` 목록: 있는 것 9개, 대표 입력 필요 4개(브랜드·CS·B2B 제안·가격 책정) |
| Human-in-the-loop 95/5 | `company/자동화_정책.json`: 계산·경보·초안은 auto, 발송·게시·환불·가격·투자·출하 해제는 approve, 무동의 광고·미성년 판매·비밀번호 전달은 forbidden. 시험으로 강제 |
| 지능 레버리지 | 아침 보고에 '전체 업무·자동 완료·대표 손이 필요한 건수'를 매일 기록 |
| 트리거 → 에이전트 연쇄 | 예: 파손 클레임 → `say` → CS 응대 대리 배정 → (품질관리부 배치 추적) → 대표 알림 |

## 3. 킹스가 그대로 따르면 안 되는 것 (제조·주류 특성)

| 글의 주장 | 킹스 현실 | 대응 |
|---|---|---|
| 한계비용 0 — 고객이 늘어도 비용이 안 늘어남 | **술은 실물.** 원료·병·주세가 병마다 듭니다. 100억이면 연 66만 병, 250kl, 주세 경감 구간도 벗어남 | 자동화로 0이 되는 것은 **관리 비용**뿐. 물량은 설비 투자·위탁, 이익률은 단가(프리미엄·선물·B2B)로 |
| 영업 에이전트가 아웃리치 이메일 자동 발송 | 광고성 정보는 수신 동의가 필요하고, 주류 광고 규정도 있음 | 제안서 **초안만 자동**, 발송은 대표 승인(정책에서 무동의 발송은 forbidden) |
| 24시간 CS가 환불까지 자동 처리 | 환불·보상은 돈과 브랜드 판단 | 답변 초안 자동, 환불·발송은 승인, 파손·이물은 즉시 대표 + 품질관리부 |

## 4. 남은 일 (대표 입력이 있어야 레버리지가 커짐)
1. 브랜드 지침·CS 기준 확인(각 10분)
2. 원가·가격표 → B2B 제안서·공장도가격 SOP 작성 가능
3. PC 연결 → `pipeline.py`를 매일 07:30 자동 실행
