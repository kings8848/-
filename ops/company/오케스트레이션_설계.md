이 문서에서 알 수 있는 것: n8n·API 기반 오케스트레이션 4단계(트리거→컨텍스트→에이전트 도구 선택→실행)를 킹스 부품으로 구현한 현황, B2B 영업 흐름 설계, 그리고 n8n을 지금 도입하지 않는 이유와 도입 시점.

# 킹스 오케스트레이션 설계 v1 (2026-11-04)

## 1. 4대 기술 스택 × 킹스
| 글의 스택 | 킹스 현재 | 판단 |
|---|---|---|
| [1] 인터페이스(Notion·Slack·Email) | Gmail(주문·정산 메일), Drive, 대표 한 줄(`workflow.py say`) | 충분. 승인 알림 채널만 미정(결정 D-0011) |
| [2] 오케스트레이터(n8n·Make) | `ops/pipeline.py`(순서·시간초과·에러 워크플로우) + `bridge.py`(경보→업무) | **지금은 Python으로 충분**(아래 4장) |
| [3] 추론 엔진(LLM) | 손사장·부장=강한 모델, CS·콘텐츠=비용 효율 모델, 계산=코드 | 글의 모델명(Claude 3.5·GPT-4o)은 구형. 역할별 배치 원칙만 채택 |
| [4] 지식·DB(Supabase·Vector DB) | CSV·JSON 원장, 회사의 기억, SOP, 법정 의무 대장 + `context.py` 키워드 검색 | 문서 수십 쪽 → 벡터 DB 불필요. S2에서 Supabase(pgvector) |

## 2. 4단계 워크플로우 × 킹스
| 단계 | 글 | 킹스 구현 |
|---|---|---|
| ① 트리거 | 메일 수신·정기 시간·폼 제출 | 정기: 예약 실행/PC 스케줄러 → `pipeline.py` · 사람: `say "문장"` · 메일 수신 트리거는 PC 연결 후 |
| ② 컨텍스트 주입(RAG) | 지침·고객·제품 정보 자동 로드 | `brief` = 반드시 아는 것 + 담당 주제 함정 + **관련 지식 자동 검색(context.py)** + 대표 답변 + 지난 지적 |
| ③ 에이전트 도구 선택 | 도구 목록을 넘기고 스스로 선택 | `company/tools.json` — 담당별 허용 도구만 brief에 실림(code·draft·outbox 구분) |
| ④ 서브 워크플로우 실행 | 기능별 독립 워크플로우 | 각 도구 = 독립 스크립트(멱등). 외부 동작은 발행 큐(approve→sent→confirm) |
| 에러 워크플로우 | 실패 시 휴대폰 알림 | `pipeline.error_workflow` — 단계별 시간초과·실패 감지 → 긴급 보고서 + 실패 기록, 이후 단계 중단. **휴대폰 알림 채널은 결정 대기** |

## 3. B2B 영업 흐름 (킹스판)
```
[1 트리거] Gmail '견적·납품·선물세트' 메일  또는  대표 say "OO기업 명절 선물 제안해"
      │
[2 전처리·코드] 기업명·담당자·수량·희망일 추출 → 거래처 원장(거래처원장 대리)에 '문의' 등록
      │
[3 B2B 영업 대리(AI)] ── 컨텍스트: 브랜드 지침 · 가격표(미입력) · 재고(입출고 대리) · 주류 통신판매·광고 규정
      ├ 도구 가치사슬: 수량별 병당 영업이익 확인(원가 입력 후)
      ├ 도구 제안서초안: 기업 맞춤 제안서
      └ 도구 발행큐등록: channel=메일, external
      │
[4 대표 승인] 승인 / 수정 / 거절  (workflow approve)
      │
[5 실행] 대표 계정으로 발송 → sent → 회신 확인 증거 → confirm → 거래처 원장 '제안 완료'
```
**막힌 곳:** 가격표·원가가 없어서 제안서 가격 칸을 채울 수 없습니다. 추정 가격은 넣지 않습니다.

## 4. n8n을 지금 쓰지 않는 이유
| 기준 | 지금 | n8n 도입 시점 |
|---|---|---|
| 외부 웹훅 입력 수 | 0개(메일·파일만) | 3개 이상(웹 폼·커머스API 웹훅·결제 알림) |
| 실행 주기 | 하루 1~2회 | 분 단위 실시간 |
| 비용 | Python 0원 | 셀프호스팅 서버 유지 필요 |
| 유지보수 | 코드+시험 28개로 회귀 확인 | 흐름도 GUI가 필요할 때 |

글에서 "셀프호스팅으로 AI 호출 비용을 줄인다"고 했지만, 셀프호스팅이 줄이는 것은 **n8n 사용료**입니다. AI 호출 비용은 같습니다. 킹스는 계산을 코드로 처리해 AI 호출 자체를 줄이는 방식으로 이미 비용을 낮추고 있습니다.
