# 회사의 기억

> 규칙(영상 '회사의 기억' 화면 적용)
> - **반드시 아는 것은 10개까지.** 모든 작업에 실리므로 하나 늘 때마다 매번 토큰이 든다. 넘치면 추가가 아니라 무엇을 내릴지 고른다.
> - **함정은 주제 태그가 맞는 담당에게만** 실린다. 고쳤으면 `[해소: 무엇을 고쳤는지 10자 이상]`을 붙인다. 해소되지 않은 함정은 계속 실린다.
> - **틀린 기억은 바로 내린다.** 틀린 기억이 중복보다 나쁘다.
