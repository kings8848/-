# 킹스 B2B 영업 파이프라인

| 단계 | 시나리오(n8n) | 킹스 구현 | 바꾼 이유 |
|---|---|---|---|
| 1 수집 | 웹 폼 Webhook / 매주 월 9시 네이버 지도·인스타 수집 | `leads.csv` — source: inbound(문의)·naver_api(공식 지역검색 API)·manual | 지도·인스타 **크롤링은 약관 위반 소지**, 공식 API는 이메일 미제공 |
| 2 프로파일링 | Claude가 매장 분석·페어링 매칭 | 코드가 키워드로 유형 판별(한우·해산물코스·바) → `sop/B2B_페어링.md` 문구 | 판별은 결정론(토큰 0), 문구는 SOP 고정 → 매번 다른 말 방지 |
| 3 제안서 | Google Docs/HTML→PDF | `proposals/리드ID.html` (PDF는 브라우저 인쇄) | 단가 미입력 칸은 '[대표 확정 후 기재]' — 추정가 금지 |
| 4 승인 | Slack 버튼 | 발행 큐(채널=메일) → **카카오톡 승인 알림**(대표 결정) → `workflow.py approve` | 대표 결정 D-0011 |
| 5 발송·CRM | Resend·Airtable, 5일 팔로업 | 대표 메일로 발송 → `leads.csv` 상태 '제안완료' → **5일 무응답 시 팔로업 경보** | 별도 메일·CRM 서비스 없이 비용 0 |

## 법규 게이트 (하나라도 걸리면 '발송 불가', 제안서 초안은 만듦)
1. **광고성 메일 사전 동의** — inbound 문의 또는 consent=Y만 메일. 나머지는 **방문·전화 제안 목록**으로 (정보통신망법 제50조)
2. **무료 시음 키트** — 세무서장 사전승인 증빙(NTS-TASTING)이 있을 때만 제안서에 포함 (시행령 제41조, 금품 제공 과태료 2천만원 이하)
3. **음식점 직접 공급 범위** — 관할 세무서 확인 증빙(NTS-DIRECT-SUPPLY) 전에는 발송 불가
4. **B2B 공급 단가** — master.json 미입력이면 발송 불가
5. **제품 확인** — 설락소주·봉신설주 25는 품목제조보고·라벨을 Drive에서 못 찾음 → 확인 전 제안 금지
